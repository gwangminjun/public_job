# 앙상블 학습(Ensemble Learning)

## 1. 개념

앙상블 학습은 **여러 개의 기본 학습기(Base Learner)를 결합하여 하나의 학습기보다 더 높은 성능과 안정적인 일반화 성능을 얻는 방법**이다.

- 비교적 간단한 학습기 여러 개를 결합할 수 있다.
- 각 학습기가 서로 다른 오류를 만들도록 다양성을 확보하는 것이 중요하다.
- 여러 학습 결과를 평균, 보팅, 가중 결합 또는 별도 학습기를 이용해 최종 결과로 만든다.

```text
여러 기본 학습기
→ 서로 다른 방식으로 학습
→ 결과 결합
→ 최종 예측
```

---

## 2. 학습기를 차별화하는 방법

### 2.1 학습 알고리즘 차별화

서로 다른 학습 알고리즘을 사용한다.

예:
- 베이즈 분류기 + K-NN
- 신경망 + SVM

### 2.2 모델 파라미터 차별화

같은 알고리즘이라도 모델 구조나 하이퍼파라미터를 다르게 설정한다.

예:
- 신경망의 뉴런 수 변경
- 트리 깊이 변경
- K-NN의 K값 변경

### 2.3 학습 데이터 차별화

각 학습기가 서로 다른 학습 데이터 또는 서로 다른 데이터 중요도를 사용하도록 한다.

---

# 3. 학습기 결합 방식

## 병렬적 결합

각 학습기를 독립적으로 학습한 후 결과를 결합한다.

대표적인 예:
- 배깅(Bagging)
- 보팅(Voting)

## 순차적 결합

앞에서 학습한 결과를 다음 학습 과정에 반영한다.

대표적인 예:
- 부스팅(Boosting)
- AdaBoost
- 캐스케이딩(Cascading)

```text
병렬적 결합 = 여러 학습기를 독립적으로 학습
순차적 결합 = 앞 학습 결과를 다음 학습에 반영
```

---

# 4. 학습 데이터 생성 방법

| 방법 | 설명 | 대표 방법 |
|---|---|---|
| 필터링 | 이전 학습 결과에 따라 사용할 데이터를 선택 | 초기 부스팅, 캐스케이딩 |
| 리샘플링 | 원본 데이터에서 여러 학습 집합을 생성 | 배깅 |
| 가중치 조정 | 데이터별 중요도를 변경 | AdaBoost |

---

# 5. 배깅(Bagging)

**Bagging = Bootstrap Aggregating**

배깅은 **부트스트랩 리샘플링으로 여러 학습 데이터 집합을 만든 뒤 각각의 학습기를 독립적으로 학습하고 결과를 결합하는 방법**이다.

```text
원본 데이터
→ 부트스트랩 샘플 1 → 학습기 1
→ 부트스트랩 샘플 2 → 학습기 2
→ 부트스트랩 샘플 3 → 학습기 3
→ 평균 또는 보팅
```

## 부트스트랩(Bootstrap)

부트스트랩은 제한된 데이터 집합에서 **복원추출(with replacement)**을 반복하여 새로운 데이터 집합을 만드는 리샘플링 방법이다.

- 같은 데이터가 여러 번 선택될 수 있다.
- 어떤 데이터는 특정 샘플에 포함되지 않을 수 있다.
- 포함되지 않은 데이터는 OOB(Out-of-Bag) 데이터로 평가에 사용할 수도 있다.

> 부트스트랩은 리샘플링 방법이며, 배깅에서는 여러 학습용 데이터 집합을 만드는 데 사용한다.

## 배깅의 고려사항

- 각 부트스트랩 데이터 집합은 보통 원본과 같은 크기로 생성한다.
- 학습 데이터의 변화에 민감한 모델에서 효과가 크다.
- 대표적으로 의사결정트리처럼 분산이 큰 모델과 잘 맞는다.

---

# 6. 평균법과 보팅법

## 평균법(Averaging)

학습기의 출력이 **연속적인 수치값**일 때 적합하다.

### 단순 평균

모든 학습기의 결과를 동일하게 반영한다.

```text
학습기 1: 10
학습기 2: 12
학습기 3: 11

최종값 = 11
```

### 가중 평균

학습기마다 서로 다른 중요도에 따라 가중치를 적용한다.

주로 **회귀 문제**에 사용한다.

## 보팅법(Voting)

주로 **분류 문제**에서 사용한다.

### 다수결 투표

가장 많은 학습기가 선택한 클래스를 최종 결과로 사용한다.

```text
학습기 1 → A
학습기 2 → A
학습기 3 → B

최종 결과 → A
```

### 가중 보팅

성능이나 중요도가 높은 학습기의 표에 더 큰 가중치를 부여한다.

---

# 7. 배깅과 보팅의 효과

## 결정경계 안정화

여러 학습기의 결과를 결합하면 특정 데이터 변화에 지나치게 민감한 결정경계를 완화할 수 있다.

## 일반화 오차 감소

개별 모델의 오류를 평균 또는 투표로 완화하여 일반화 성능을 높일 수 있다.

특히 배깅은 일반적으로 **분산(Variance)을 감소시키는 효과**가 크다.

---

# 8. 부스팅(Boosting)

부스팅은 **간단한 학습기들이 서로의 부족한 부분을 보완하도록 순차적으로 학습하는 방법**이다.

- 먼저 학습된 결과를 다음 학습 과정에 사용한다.
- 이전 학습기가 잘 처리하지 못한 데이터에 다음 학습기가 더 집중한다.

```text
학습기 1
→ 틀린 부분 확인
→ 학습기 2가 보완
→ 학습기 3가 다시 보완
→ 결과 결합
```

초기의 부스팅 방식에서는 잘못 분류된 데이터를 다음 학습 집합에 추가하면서 데이터 집합이 커질 수 있다.

AdaBoost는 같은 데이터 집합을 반복 사용하면서 **데이터의 가중치를 조정**하는 방식으로 이를 해결한다.

---

# 9. AdaBoost

**AdaBoost(Adaptive Boosting)**는 동일한 데이터 집합을 반복 사용하되 데이터의 **가중치**를 변경하여 학습에 변화를 주는 부스팅 알고리즘이다.

핵심 아이디어:

```text
잘 맞힌 데이터
→ 상대적 가중치 감소

틀린 데이터
→ 가중치 증가

다음 학습기
→ 이전에 틀린 데이터에 더 집중
```

## 수행 과정

1. 모든 데이터에 동일한 초기 가중치를 부여한다.
2. 기본 학습기를 학습한다.
3. 분류 오류를 계산한다.
4. 잘못 분류된 데이터의 가중치를 증가시킨다.
5. 변경된 가중치를 반영해 다음 학습기를 학습한다.
6. 위 과정을 반복한다.
7. 각 학습기의 성능을 반영한 **가중 보팅**으로 최종 결과를 결정한다.

```text
AdaBoost
= 같은 데이터 반복 사용
+ 데이터 가중치 조정
+ 학습기 가중치 적용
+ 가중 보팅
```

---

# 10. 배깅 vs 부스팅

| 구분 | 배깅 | 부스팅 |
|---|---|---|
| 학습 방식 | 병렬적 | 순차적 |
| 데이터 처리 | 부트스트랩 리샘플링 | 이전 학습 결과 반영 |
| 모델 관계 | 독립적 | 앞 모델에 의존 |
| 주요 효과 | 분산 감소 | 이전 오류 보완 |
| 대표 알고리즘 | Random Forest | AdaBoost, Gradient Boosting |

```text
배깅 = 여러 모델을 독립적으로 학습
부스팅 = 앞 모델의 실수를 다음 모델이 보완
```

---

# 11. 스태킹(Stacking)

여러 기본 학습기의 결과를 **또 다른 학습기(메타 학습기)의 입력으로 사용하여 최종 결합 방법까지 학습하는 방식**이다.

```text
기본 학습기 1 ─┐
기본 학습기 2 ─┼→ 메타 학습기 → 최종 결과
기본 학습기 3 ─┘
```

```text
평균/보팅 = 정해진 규칙으로 결합
스태킹 = 결합 방법 자체를 학습
```

---

# 12. 캐스케이딩(Cascading)

캐스케이딩은 **서로 다른 복잡도의 학습기를 순차적으로 결합**하는 방법이다.

- 간단한 학습기로 먼저 판단
- 어려운 데이터만 더 복잡한 다음 학습기로 전달
- 계산 효율을 높이면서 안정적인 성능을 얻는 것이 목적

```text
간단한 학습기
→ 판단이 어려운 데이터
→ 더 복잡한 학습기
→ 최종 판단
```

---

# 13. 전문가 혼합(Mixture of Experts)

전문가 혼합은 여러 학습기의 출력을 **가중합하여 하나의 최종 학습기 출력으로 만드는 방법**이다.

- 각각의 학습기를 전문가(Expert)라고 본다.
- 입력 데이터에 따라 각 전문가의 중요도를 다르게 적용할 수 있다.

```text
전문가 1 ─┐
전문가 2 ─┼→ 가중합 → 최종 출력
전문가 3 ─┘
```

---

# 14. 주요 결합 방법 비교

| 방법 | 적합한 문제 | 결합 방식 |
|---|---|---|
| 단순 평균 | 회귀 | 출력값 평균 |
| 가중 평균 | 회귀 | 가중치를 적용한 평균 |
| 다수결 보팅 | 분류 | 가장 많은 클래스 선택 |
| 가중 보팅 | 분류 | 학습기별 중요도 반영 |
| 스태킹 | 분류/회귀 | 메타 학습기가 결합 방법 학습 |
| 전문가 혼합 | 분류/회귀 | 전문가 출력을 가중합 |
