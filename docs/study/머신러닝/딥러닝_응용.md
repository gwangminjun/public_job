# 딥러닝 응용 정리

## 1. 객체인식을 위한 CNN 모델

### ILSVRC와 CNN의 발전

- **ILSVRC(ImageNet Large Scale Visual Recognition Challenge)**를 통해 객체인식을 위한 다양한 CNN 모델이 등장하였다.
- **2012년 AlexNet이 우승**하면서 딥러닝 기반 영상인식의 성능이 크게 주목받기 시작하였다.

### 주요 CNN 모델

| 모델 | 등장/성과 | 핵심 구조 | 특징 | Top-5 오류율(교재 기준) |
|---|---|---|---|---:|
| **AlexNet** | 2012년 우승 | 5개 Convolution + 3개 Fully Connected, 총 8층 | 딥러닝 기반 객체인식의 대표적 시작점 | 16.4% |
| **VGG** | 2014년 2등 | VGG-11, 13, 16, 19 등 | 층수와 필터 구성에 따른 다양한 버전, 전이학습에서 많이 사용 | 7.3% |
| **GoogLeNet** | 2014년 우승 | **Inception Module**, 22층 | 여러 크기의 필터를 병렬적으로 적용 | 6.7% |
| **ResNet** | 2015년 우승 | **Residual Module**, Skip Connection, 152층 | 매우 깊은 네트워크를 안정적으로 학습 | 3.57% |

### ResNet

- 핵심 구조: **잔차 모듈(Residual Module)**
- **Skip Connection**을 이용하여 일부 층을 건너뛰어 입력 정보를 뒤쪽 층으로 전달한다.
- 장점
  - 매우 깊은 신경망에서도 학습이 가능하다.
  - 네트워크가 깊어질 때 발생하는 성능 저하 문제를 완화한다.

> **암기**: AlexNet → 2012 / VGG → 다양한 층 / GoogLeNet → Inception / ResNet → Residual + Skip Connection

## 2. 영상이해를 위한 딥러닝

### 다중 객체 검출(Object Detection)

- 한 영상에 포함된 **여러 객체를 모두 검출**하고 각 객체의 **종류와 위치**를 찾는 문제이다.
- 대표 모델
  - **R-CNN**
  - **Faster R-CNN**
  - **YOLO**

### R-CNN

- 영상에서 최대 약 **2,000개의 후보 영역(Region Proposal)**을 추출한다.
- 각 후보 영역마다 CNN을 적용하여 객체를 인식한다.
- 후보 영역 각각에 CNN 연산을 수행하므로 처리 속도가 느리다.
- 이후 **Faster R-CNN**으로 발전하였다.

### Faster R-CNN

- R-CNN 계열의 다중 객체 검출 모델이다.
- 후보 영역 생성 과정까지 신경망에 포함하여 R-CNN보다 효율적으로 객체를 검출한다.

### YOLO

- **You Only Look Once**
- 객체의 **탐지와 인식을 한 번에 수행**한다.
- 영상 전체를 한 번에 처리하여 빠른 객체 검출이 가능하다.
- **실시간 동영상 객체 검출**에 활용할 수 있다.

### 객체인식과 객체검출 비교

- **객체인식(Image Classification)**
  - 영상 전체가 어떤 클래스인지 판단
  - AlexNet, VGG, GoogLeNet, ResNet
- **객체검출(Object Detection)**
  - 영상 속 객체의 종류와 위치를 함께 판단
  - R-CNN, Faster R-CNN, YOLO

## 3. 영상설명(Image Captioning)

### 영상설명 문제

- 영상에 포함된 의미를 종합적으로 이해하고 이를 설명하는 **자연어 문장**을 생성하는 문제이다.
- 영상처리와 자연어처리를 결합한 응용 분야이다.

### Show and Tell

- 영상 특징 추출과 자연어 문장 생성을 결합한 모델이다.
- 구성
  - 영상처리: **GoogLeNet**
  - 문장생성: **LSTM**
- CNN으로 영상 특징을 추출하고 LSTM으로 설명 문장을 생성한다.

### Show, Attend and Tell

- Show and Tell과 유사한 영상설명 모델이다.
- 차이점
  - 문장의 각 단어를 생성할 때 영상의 관련 부분에 **Attention**을 적용한다.
  - 어떤 영상 영역에 집중하여 단어를 생성했는지 표현할 수 있다.

> **암기**: Show and Tell = CNN + LSTM / Show, Attend and Tell = CNN + LSTM + Attention

## 4. 오토인코더(Autoencoder)

### 개념

- 입력 데이터가 주어졌을 때 **출력이 입력과 같아지도록 학습**하는 신경망이다.
- 입력에 포함된 정보를 압축하였다가 다시 복원하는 과정에서 **축약된 특징**을 학습한다.

### 구성

1. **Encoder(인코더)**
   - 입력 데이터를 저차원의 특징으로 압축한다.
2. **Latent Representation / z**
   - 압축된 특징 표현
3. **Decoder(디코더)**
   - 압축된 특징을 이용하여 원래 입력을 복원한다.

### 목적

- 핵심 목적: **축약된 특징 `z`를 얻는 것**
- 입력의 중요한 특징을 압축하여 표현할 수 있다.

> 입력 `x` → Encoder → **z** → Decoder → 복원된 입력 `x'`

## 5. U-Net

### 개념

- **CNN 기반의 변형된 오토인코더 구조**이다.
- **의료영상의 영상분할(Image Segmentation)**을 위해 개발되었다.

### 구조

- 전체적으로 **U자형 구조**를 가진다.
- **Contracting Path**
  - 인코더 역할
  - 영상의 특징을 추출하고 압축한다.
- **Expanding Path**
  - 디코더 역할
  - 압축된 특징으로부터 공간 정보를 복원한다.
- **Skip Connection**
  - Contracting Path의 특징을 Expanding Path에 직접 전달한다.
  - 위치 및 세부 정보를 효과적으로 복원하는 데 도움을 준다.

### 핵심

- **목적**: 영상분할
- **대표 응용**: 의료영상 분할
- **구조**: Contracting Path + Expanding Path + Skip Connection

## 6. GAN(Generative Adversarial Network)

### 개념

- 2014년에 등장한 대표적인 **영상생성 모델**이다.
- 이후 영상 변환 분야로도 확장되었다.

### 구성

GAN은 두 개의 네트워크로 구성된다.

1. **Generator(G, 생성기)**
   - 가짜 데이터를 생성한다.
   - 판별기를 속여 가짜 데이터를 실제 데이터처럼 판단하도록 학습한다.

2. **Discriminator(D, 판별기)**
   - 입력 데이터가 실제 데이터인지 생성기가 만든 가짜 데이터인지 구분한다.

### 학습 방식

- 두 네트워크는 **서로 상반된 목적**을 가지고 번갈아 학습한다.
- 생성기 G
  - 가짜 영상을 실제 영상처럼 생성
  - 판별기가 가짜 영상을 **실제(1)**라고 판단하도록 만드는 것이 목표
- 판별기 D
  - 실제 영상과 가짜 영상을 정확히 구분
  - 생성된 가짜 영상에 대해 **가짜(0)**라고 판단하도록 만드는 것이 목표

### GAN의 최종 목적

- 생성기가 최대한 진짜와 비슷한 영상을 만들어 **판별기를 속일 수 있도록 학습**하는 것

### 대표 변형 모델

- **CycleGAN**
- **CoGAN**
- **Progressive GAN**
- **StyleGAN**

> **암기**: GAN = Generator + Discriminator / 생성기는 속이고, 판별기는 구분한다.

## 8. 시험 암기 포인트

### 객체인식

- **AlexNet, VGG, GoogLeNet, ResNet → 객체인식 모델**
- **AlexNet → 2012년 ILSVRC 우승, 5개의 Convolution층 + 3개의 완전연결층**
- **VGG → 11, 13, 16, 19층 버전, 전이학습에 많이 활용**
- **GoogLeNet → Inception Module, 22층**
- **ResNet → Residual Module, Skip Connection, 152층**

### 객체검출

- **R-CNN, Faster R-CNN, YOLO → 다중 객체 검출 모델**
- **YOLO → 객체 탐지와 인식을 한 번에 수행, 실시간 동영상에 사용 가능**

- **Show and Tell → 영상처리 + 자연어처리, GoogLeNet + LSTM**

- **Autoencoder → Encoder + Decoder, 목적은 축약된 특징 z 획득**
- **U-Net → CNN 기반 변형 오토인코더, 의료영상 분할**

## 11. 자연어처리(NLP) 전처리와 텍스트 표현

### 토큰화(Tokenization)

- **말뭉치(Corpus)를 의미 있는 기본 단위인 토큰(Token)으로 나누는 작업**이다.
- 토큰의 단위는 단어, 형태소, 서브워드 등이 될 수 있다.

### 정제(Cleaning)

- 데이터 분석에 방해가 되는 **노이즈 데이터를 제거**하는 과정이다.
- 불필요한 특수문자, HTML 태그, 중복 공백 등 분석 목적에 필요 없는 요소를 제거한다.

### 정규화(Normalization)

- **표현 방법이 다른 단어들을 하나의 형태로 통합**하는 과정이다.
- 같은 의미를 가진 표현을 일관된 형태로 만들어 데이터의 중복과 변형을 줄인다.

> **암기**: 토큰화 = 나누기 / 정제 = 노이즈 제거 / 정규화 = 표현 통일

## 12. 텍스트 표현 방법

### 원핫 인코딩(One-Hot Encoding)

- 말뭉치에서 얻은 **단어 집합(Vocabulary)의 각 단어를 고유한 정수로 매핑**한다.
- 이후 각 단어를 **하나의 원소만 1이고 나머지는 0인 원핫 벡터**로 표현한다.

#### 장점

- 단어를 단순하고 명확하게 구분할 수 있다.

#### 단점

- 단어 수가 많아질수록 벡터의 **차원이 매우 커진다.**
- 대부분의 값이 0인 **고차원 희소 벡터(Sparse Vector)**가 된다.
- 단어 사이의 **의미적 유사성을 표현할 수 없다.**

### BoW(Bag of Words)

- 문서에서 **각 단어가 몇 번 출현했는지 빈도수를 이용하여 텍스트를 표현**하는 방법이다.
- 단어의 출현 순서나 위치는 고려하지 않는다.

#### 특징

- 문서에서 많이 등장하는 단어를 잘 표현할 수 있다.
- 단어의 순서와 문맥 정보가 사라진다는 단점이 있다.

### DTM(Document-Term Matrix)

- **여러 문서에서 각 단어가 출현한 빈도수를 행렬 형태로 표현**한 것이다.
- 일반적으로
  - 행 → 문서
  - 열 → 단어
  - 값 → 해당 문서에서 단어가 출현한 횟수

### DF(Document Frequency)

- 특정 단어가 **몇 개의 문서에서 등장했는지**를 나타낸다.

### TF-IDF(Term Frequency-Inverse Document Frequency)

- **문서 내부의 단어 빈도(TF)**와 **전체 문서에서의 단어 출현 정도(DF)**를 함께 고려하는 텍스트 표현 방법이다.
- 특정 문서에서 자주 나타나지만 전체 문서에서는 드물게 등장하는 단어에 높은 값을 부여한다.
- 여러 문서에 공통적으로 자주 등장하는 단어는 상대적으로 낮은 값을 갖는다.

> **암기**: BoW = 단어 빈도 / DTM = 문서×단어 빈도 행렬 / DF = 단어가 등장한 문서 수 / TF-IDF = 문서 내 빈도 + 전체 문서 빈도 고려

## 13. 워드 임베딩(Word Embedding)

### 개념

- 단어를 **의미 정보를 포함하는 저차원의 실수 벡터**로 표현하는 방법이다.
- 고차원의 희소한 원핫 벡터를 **저차원의 밀집 벡터(Dense Vector)**로 변환한다.
- 의미가 비슷한 단어는 벡터 공간에서도 가까운 위치에 표현될 수 있다.

### 원핫 벡터 vs 임베딩 벡터

| 구분 | 원핫 벡터 | 임베딩 벡터 |
|---|---|---|
| 값 | 0 또는 1 | 실수값 |
| 차원 | 단어 집합 크기만큼 고차원 | 상대적으로 저차원 |
| 형태 | 희소 벡터 | 밀집 벡터 |
| 단어 간 유사성 | 표현 어려움 | 의미적 유사성 표현 가능 |
| 학습 여부 | 단순 인코딩 | 학습을 통해 벡터 획득 가능 |

### 대표적인 워드 임베딩 방법

- **Word2Vec**
- **LSA**
- **GloVe**

## 14. Word2Vec

### 개념

- 대표적인 **워드 임베딩 방법**이다.
- 단어의 주변 문맥을 이용하여 단어를 저차원의 실수 벡터로 학습한다.
- 시험 관점에서는 **원핫 벡터를 입력으로 받아 학습된 가중치 행렬을 통해 저차원 임베딩 벡터로 사영**한다고 이해할 수 있다.

### CBOW(Continuous Bag of Words)

- **주변 단어들을 입력**으로 받아 **중심 단어를 예측**한다.

```text
주변 단어 → 중심 단어 예측
```

### Skip-gram

- **중심 단어를 입력**으로 받아 **주변 단어를 예측**한다.

```text
중심 단어 → 주변 단어 예측
```

> **암기**: CBOW = 주변 → 중심 / Skip-gram = 중심 → 주변

---

## 15. 언어 모델(Language Model)

### 개념

- **단어 시퀀스를 입력받아 확률값을 출력하는 함수**이다.
- 주어진 단어 시퀀스가 자연어 표현으로 얼마나 적절한지를 확률적으로 평가한다.
- 다음 단어의 확률을 앞선 단어들에 대한 **조건부 확률**로 표현할 수 있다.
- 전통적으로 RNN, LSTM 등을 이용하여 구현하였고, 이후 Transformer 계열 모델이 널리 사용되었다.

### 관련 모델

- Seq2Seq
- Attention
- Transformer
- BERT
- GPT 계열

---

## 16. Seq2Seq

### 개념

- **입력 시퀀스로부터 다른 도메인의 출력 시퀀스를 생성**하는 모델이다.
- 기계번역, 문장 생성 등에 활용된다.

### 구조

- **Encoder(인코더)**
  - 입력 시퀀스를 읽어 특징 정보를 추출한다.
- **Decoder(디코더)**
  - 인코더에서 전달받은 정보를 이용하여 출력 시퀀스를 생성한다.

```text
입력 시퀀스 → Encoder → 특징 벡터 → Decoder → 출력 시퀀스
```

### 문제점

- 기본 Seq2Seq에서는 인코더의 정보를 **하나의 고정된 특징 벡터(Context Vector)**로 압축한다.
- 입력 시퀀스가 길어질수록 정보 손실이 커져 성능이 저하될 수 있다.

---

## 17. Attention

### 등장 배경

- Seq2Seq의 **고정된 하나의 특징 벡터에 모든 정보를 압축하는 문제**를 완화하기 위해 등장하였다.

### 개념

- 디코더가 출력 단어를 생성할 때마다 **인코더의 전체 상태를 확인하고, 현재 출력에 중요한 부분에 선택적으로 주의(Attention)**를 기울이는 방식이다.
- 각 인코더 상태의 중요도를 계산하여 필요한 정보를 선택적으로 사용한다.

### 핵심

```text
기본 Seq2Seq
인코더 정보 → 하나의 고정 벡터 → 디코더

Attention
인코더의 전체 상태 → 필요한 부분을 선택적으로 참조 → 디코더
```

> **암기**: Attention = 출력할 때마다 입력의 중요한 부분을 다시 선택해서 본다.

---

## 18. Transformer

### 개념

- **RNN의 순환 구조를 사용하지 않고 Attention을 중심으로 구성한 모델**이다.
- 특히 **Self-Attention**을 이용하여 문장 내부 단어들 사이의 관계를 학습한다.

### 특징

- RNN처럼 단어를 한 번에 하나씩 순차적으로 처리할 필요가 적어 **병렬 연산이 가능**하다.
- 여러 개의 인코더/디코더 블록과 Attention 구조를 사용한다.
- 긴 거리의 단어 관계를 효과적으로 학습할 수 있다.

> **암기**: Transformer = RNN 제거 + Attention 중심 + 병렬 처리

---

## 19. BERT

### 개념

- Google이 발표한 **Transformer 기반 사전학습 언어 모델**이다.
- Transformer의 **Encoder 구조**를 활용한다.

### 학습 과정

1. **사전학습(Pre-training)**
   - 대규모 말뭉치를 이용하여 일반적인 언어 표현을 학습
2. **미세조정(Fine-tuning)**
   - 특정 자연어처리 문제에 맞게 추가 학습

### BERT의 3가지 임베딩

BERT의 입력 표현은 다음 세 임베딩을 더해서 구성한다.

1. **Token Embedding**
   - 입력 토큰 자체를 표현
2. **Segment Embedding**
   - 문장 A와 문장 B 등 문장 구분 정보를 표현
3. **Position Embedding**
   - 토큰의 위치 정보를 표현

> **암기**: BERT 3대 임베딩 = Token + Segment + Position

---

## 20. 대규모 언어모델(LLM)

### 개념

- 매우 많은 파라미터와 대규모 텍스트 데이터를 이용하여 학습한 언어 모델이다.
- 강의/교재에서는 **100억 개 이상의 파라미터를 가진 대규모 모델**로 설명할 수 있다.
- 실제 LLM이라는 용어는 특정 파라미터 수 하나로만 엄격하게 구분되지는 않는다.

### LLM 개발 및 활용 과정

1. **사전학습(Pre-training)**
   - 대규모 데이터로 일반적인 언어 능력을 학습
2. **미세조정(Fine-tuning)**
   - 특정 목적이나 작업에 맞도록 추가 학습
3. **추론(Inference)**
   - 학습된 모델을 이용하여 실제 입력에 대한 결과 생성
4. **평가(Evaluation)**
   - 모델의 정확성, 품질, 안정성 등을 평가

> **암기**: 사전학습 → 미세조정 → 추론 → 평가

---

## 21. Few-shot CoT vs Zero-shot CoT

### CoT(Chain of Thought)

- 모델이 문제를 풀 때 **중간 추론 과정을 단계적으로 생성하도록 유도하는 프롬프트 기법**이다.

### Few-shot CoT

- 프롬프트에 **몇 개의 문제와 단계별 추론 예시**를 함께 제공한다.
- 모델은 제공된 예시의 추론 패턴을 참고하여 새로운 문제를 해결한다.

```text
예제 문제 + 추론 과정 + 정답
예제 문제 + 추론 과정 + 정답
→ 새로운 문제
```

### Zero-shot CoT

- 별도의 추론 예시를 주지 않고 **"단계적으로 생각해 보자"와 같은 지시**를 통해 추론을 유도한다.

```text
새로운 문제
+ 단계적으로 생각하라는 지시
```

### 비교

| 구분 | Few-shot CoT | Zero-shot CoT |
|---|---|---|
| 예시 제공 | O | X |
| 추론 예시 | 여러 개 제공 | 제공하지 않음 |
| 핵심 | 예시를 따라 추론 | 지시만으로 단계적 추론 유도 |

> **암기**: Few-shot CoT = 예시 있음 / Zero-shot CoT = 예시 없이 추론 지시

## 23. 자연어처리 O/X 포인트

- **토큰화는 말뭉치를 의미 있는 기본 단위로 나누는 작업이다. → O**
- **정제는 표현 방법이 다른 단어를 하나의 단어로 통합하는 과정이다. → X**
  - 표현 통합은 **정규화**
- **원핫 인코딩은 단어 간 의미적 유사성을 잘 표현한다. → X**
- **BoW는 단어의 출현 순서를 고려한다. → X**
- **TF-IDF는 문서 내 빈도와 전체 문서에서의 등장 정도를 함께 고려한다. → O**
- **워드 임베딩은 단어를 저차원 실수 벡터로 표현할 수 있다. → O**
- **CBOW는 중심 단어를 입력하여 주변 단어를 예측한다. → X**
  - CBOW = 주변 → 중심
- **Skip-gram은 중심 단어를 이용하여 주변 단어를 예측한다. → O**
- **기본 Seq2Seq는 Encoder와 Decoder로 구성된다. → O**
- **Attention은 인코더의 정보를 하나의 고정 벡터만으로 사용한다. → X**
- **Transformer는 RNN의 순환 구조를 핵심으로 사용한다. → X**
- **BERT는 Token, Segment, Position의 세 종류 임베딩을 사용한다. → O**
- **Few-shot CoT는 추론 예시 없이 지시문만 제공한다. → X**
  - 예시 없이 지시만 제공하는 것은 **Zero-shot CoT**

## 25. 강화학습(Reinforcement Learning)

### 개념

- **최종 목표를 지정**하고, 매 순간 학습 시스템이 취한 행동의 결과에 따라 **보상(Reward)**을 제공하는 학습 방법이다.
- 학습의 목적은 최종적으로 얻는 **누적 보상을 최대화**하는 것이다.
- 에이전트는 주어진 **정책(Policy)**에 따라 행동을 선택한다.
- 최적의 정책을 찾으면 최적의 행동을 선택할 수 있고, 이를 통해 누적 보상을 최대화할 수 있다.

> **암기**: 강화학습 = 행동 → 보상 → 누적 보상 최대화

---

## 26. 마르코프 결정 프로세스(MDP)

### 개념

- **마르코프 결정 프로세스(Markov Decision Process, MDP)**는 에이전트와 환경의 상호작용 문제를 수학적으로 표현한 것이다.
- 다음 정보의 튜플로 구성된다.

1. **가능한 상태의 유한집합**
2. **가능한 행동의 유한집합**
3. **상태 전이확률**
4. **보상 함수**
5. **할인율**

### 상태 전이확률

- 주어진 상태에서 특정 행동을 선택했을 때 **다른 상태로 전이될 확률**을 나타낸다.

### 마르코프 성질(Markov Property)

- 다음 행동이나 상태의 결정은 **현재 상태에 의해서만 결정**된다는 성질이다.
- 현재 상태 이전에 어떤 선택을 했는지는 직접적인 영향을 미치지 않는다.

> **암기**: 마르코프 성질 = 과거보다 **현재 상태**가 중요

---

## 27. 정책과 수익

### 정책(Policy)

- **에이전트가 행동을 선택할 때 사용하는 규칙**이다.
- 주어진 MDP에서 최적의 행동을 결정하는 **최적 정책**을 찾는 것이 학습의 목표이다.

### 수익(Return / Gain)

- 특정 시점부터 앞으로 얻어지는 보상들에 **할인율을 적용하여 합산한 값**이다.
- 즉, **총할인보상**을 의미한다.

> **암기**: 정책 = 행동 선택 규칙 / 수익 = 할인된 미래 보상의 합

---

## 28. 가치함수(Value Function)

### 상태 가치함수(State-Value Function)

- 상태 `s`에서 시작하여 **주어진 정책에 따라 행동했을 때 얻을 수 있는 기대 보상**이다.

### 행동 가치함수(Action-Value Function)

- 주어진 정책에 따라 상태 `s`에서 행동 `a`를 선택했을 때 **얻을 수 있는 기대 보상**이다.
- 행동 가치함수를 **Q-함수(Q-function)**라고도 한다.

### 최적 상태 가치함수

- 가능한 모든 정책에 대해 **가장 큰 값을 갖는 상태 가치함수**이다.

### 최적 행동 가치함수

- 가능한 모든 정책에 대해 **가장 큰 값을 갖는 행동 가치함수**이다.

### 최적 정책

- **최적 행동 가치함수**를 구한 뒤 이를 최대화하는 행동을 선택함으로써 구할 수 있다.

### 비교

| 구분 | 의미 |
|---|---|
| **상태 가치함수** | 상태 `s`에서 시작했을 때 기대 보상 |
| **행동 가치함수** | 상태 `s`에서 행동 `a`를 했을 때 기대 보상 |
| **Q-함수** | 행동 가치함수 |
| **최적 상태 가치함수** | 모든 정책 중 최대 상태 가치 |
| **최적 행동 가치함수** | 모든 정책 중 최대 행동 가치 |

> **암기**: 상태 가치 = `s` / 행동 가치(Q) = `s + a`

---

## 29. Q-학습(Q-Learning)

### Q-함수와 Q-값

- **Q-함수** = 행동 가치함수
- **Q-값(Q-value)** = 주어진 상태-행동 쌍에 대한 기대 보상, 즉 Q-함수의 값

### Q-학습의 개념

- **최적 정책을 얻기 위해 최적의 Q-함수를 추정하는 방법**이다.

### Q-학습 과정

1. 현재 상태에서 행동을 선택한다.
2. 선택한 행동을 수행한다.
3. 즉각적인 보상을 얻는다.
4. 새로운 상태를 관측한다.
5. 보상과 새로운 상태 정보를 이용하여 **Q-함수를 갱신**한다.
6. 위 과정을 반복하면서 최적 Q-함수를 추정한다.

### 할인율

- Q-함수 갱신 과정에서 할인율을 적용하면 미래 보상을 현재 시점에서 평가할 수 있다.
- 자료에서는 이를 통해 **더 빠른(짧은) 경로를 적절하게 평가**할 수 있다고 설명한다.

> **암기**: Q-learning = 행동 → 보상/새 상태 → Q 갱신 → 반복

---

## 30. Q-테이블(Q-Table)

### 개념

- **이산적인 Q-함수의 값을 테이블 형태로 표현**한 것이다.
- 상태와 행동의 조합에 대응하는 Q-값을 저장한다.

### 한계

- 상태와 행동의 수가 많아질수록 테이블의 크기가 커진다.
- 많은 상태를 표현해야 하는 문제에서는 **비효율적**이다.
- 이러한 한계를 해결하기 위해 Q-함수를 신경망으로 근사하는 **Q-신경망**을 사용할 수 있다.

> **암기**: Q-table 한계 = 상태가 많아지면 비효율적 → Q-신경망

---

## 31. Q-학습의 행동 선택 전략

### 탐험

- **랜덤하게 다양한 행동을 선택**하는 전략이다.
- 아직 충분히 시도하지 않은 행동을 폭넓게 확인한다.

### 탐사

- 현재까지 학습된 **Q-함수 정보를 바탕으로 최적의 행동을 선택**하는 전략이다.

### 혼합 전략: 엡실론 탐욕 방법

- 탐험과 탐사를 혼합하여 사용하는 전략이다.
- 시간이 지남에 따라
  - **탐험 정도는 감소**시키고
  - **탐사 정도는 증가**시킨다.

| 전략 | 핵심 |
|---|---|
| **탐험** | 랜덤하게 다른 행동 선택 |
| **탐사** | 현재 Q-함수 기준으로 좋은 행동 선택 |
| **엡실론 탐욕** | 탐험 + 탐사의 혼합 |

> **암기**: 초반 탐험 ↑ → 학습이 진행될수록 탐사 ↑

---

## 32. 결정론적 모델 vs 비결정론적 모델

| 구분 | 결정론적 모델 | 비결정론적 모델 |
|---|---|---|
| 임의성 | 없음 | 존재 |
| 동일 초기 조건/파라미터 | 항상 동일한 출력 | 서로 다른 출력 가능 |
| 출력 결정 | 초기 조건과 파라미터에 의해 결정 | 임의성이 함께 작용 |

### 비결정론적 모델의 Q-학습

- 비결정론적 모델에서는 같은 상태와 행동에서도 결과가 달라질 수 있다.
- 자료에서는 Q-학습 갱신 규칙에 **학습률과 유사한 개념의 신뢰 요소**를 사용한다고 설명한다.

---

## 33. Q-신경망(Q-Network)

### 개념

- Q-함수를 테이블로 저장하지 않고, **신경망을 이용한 근사함수로 표현하고 추정**하는 방법이다.

### 입력과 출력

- **입력층**: 현재 상태
- **출력층**: 주어진 상태에서 가능한 **각 행동에 대한 Q-값**

```text
상태 → Q-신경망 → 행동1 Q값
                 행동2 Q값
                 행동3 Q값
                 ...
```

### 문제점

- Q-신경망은 학습이 **불안정**할 수 있다.
- 수렴이 보장되지 않는 문제가 있어 이를 개선한 **DQN(Deep Q-Network)**이 등장하였다.

---

## 34. DQN(Deep Q-Network)

### 개념

- **Q-신경망을 CNN 기반의 심층 신경망으로 표현한 모델**이다.
- 원래 영상의 **픽셀 데이터**를 입력으로 받아 미래 보상을 추정하는 **행동 가치함수의 근사함수**이다.

### 특징

- 아타리(Atari) 비디오 게임에 적용하여 성능을 입증하였다.
- 초기 구조는
  - **2개의 Convolution 층**
  - **2개의 Fully Connected 층**
  으로 구성되었다.

### Q-신경망 학습의 불안정성 해결 방법

- **경험 재현(Experience Replay)**
- **목표망(Target Network)**

> **암기**: DQN = CNN 기반 Q-신경망 + 경험 재현 + 목표망

---

## 36. 강화학습 O/X 포인트

- **강화학습의 목적은 최종 누적 보상을 최대화하는 것이다. → O**
- **정책은 에이전트가 행동을 선택하는 규칙이다. → O**
- **마르코프 성질에서는 다음 행동이 과거의 모든 상태에 의해 직접 결정된다. → X**
  - 현재 상태에 의해서만 결정
- **상태 가치함수는 상태 `s`에서 시작했을 때의 기대 보상이다. → O**
- **행동 가치함수는 Q-함수라고도 한다. → O**
- **Q-학습은 최적 정책을 얻기 위해 최적 Q-함수를 추정한다. → O**
- **Q-테이블은 상태 공간이 매우 커져도 항상 효율적이다. → X**
  - 상태가 많으면 비효율적
- **Q-신경망의 입력에는 상태가 주어지고 출력은 각 행동에 대한 Q-값으로 구성된다. → O**
- **DQN은 영상 픽셀 데이터를 입력으로 사용할 수 있다. → O**
- **DQN은 Q-신경망의 학습 안정성을 위해 경험 재현과 목표망을 사용한다. → O**
- **결정론적 모델은 같은 초기 조건과 파라미터에서 서로 다른 결과가 나올 수 있다. → X**
  - 비결정론적 모델에서 가능

## 37. 강화학습 초압축 암기

```text
강화학습
목적 → 누적 보상 최대화
정책 → 행동 선택 규칙

MDP
상태집합 + 행동집합 + 상태전이확률 + 보상함수 + 할인율
마르코프 성질 → 현재 상태만 중요

가치함수
상태 가치 → 상태 s의 기대보상
행동 가치(Q) → 상태 s + 행동 a의 기대보상
최적 정책 → 최적 행동 가치함수를 최대화

Q-learning
Q함수 = 행동 가치함수
Q값 = 상태-행동 쌍의 기대보상
행동 → 보상/새 상태 → Q 갱신 → 반복
Q-table → 상태가 많으면 비효율적

행동 선택
탐험 → 랜덤
탐사 → 현재 Q기준 최적 행동
엡실론 탐욕 → 탐험 + 탐사

Q-network
입력 → 상태
출력 → 각 행동의 Q값
문제 → 학습 불안정

DQN
CNN 기반 심층 Q-신경망
픽셀 입력 → 미래 보상 추정
초기 구조 → 2 Conv + 2 FC
안정화 → 경험 재현 + 목표망
```
