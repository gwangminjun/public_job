# 특징 추출(Feature Extraction)

## 1. 특징 추출의 개념

특징 추출은 주어진 원래 데이터 \(x\)를 변환하여 새로운 **특징 벡터 \(y\)** 로 표현하는 과정이다.

- 데이터 분석에 불필요한 정보는 제거
- 분석에 핵심이 되는 정보만 추출
- 차원을 축소하여 학습 시스템의 효율을 향상
- 데이터 저장 공간과 계산량을 줄일 수 있음
- 중요한 정보는 최대한 유지하면서 더 간단한 표현으로 변환

```text
원본 데이터 x
→ 특징 추출
→ 새로운 특징 벡터 y
```

---

# 2. 특징 추출의 목적

특징 추출의 주요 목적은 다음과 같다.

- 불필요한 정보 제거
- 중요한 정보 강조
- 데이터 차원 축소
- 학습 속도 향상
- 저장 공간 감소
- 잡음의 영향 감소
- 데이터 시각화

---

# 3. 변환 함수의 종류

특징 추출을 위한 변환 함수는 크게 두 종류로 나눌 수 있다.

## 3.1 선형 변환

입력 데이터에 행렬 연산을 적용하여 특징을 추출한다.

\[
y = W^T x
\]

- \(x\): 원래 입력 데이터
- \(W\): 변환 행렬
- \(y\): 변환된 특징 벡터

대표적인 방법:

- PCA
- LDA

## 3.2 비선형 변환

데이터가 복잡한 비선형 구조를 가지는 경우 비선형 함수를 이용하여 새로운 특징 공간으로 변환한다.

대표적인 접근:

- 매니폴드 학습
- t-SNE
- Isomap

---

# 4. 특징 추출의 접근 방법

## 4.1 수작업에 의한 특징 추출

사람이 문제의 특성을 분석하여 직접 중요한 특징을 설계하는 방법이다.

예:

- 이미지의 모서리
- 색상
- 모양
- 통계량

## 4.2 표현학습에 의한 특징 추출

기계가 데이터로부터 중요한 특징을 자동으로 학습하는 방법이다.

대표적인 예:

- 신경망
- 딥러닝
- 오토인코더

```text
수작업 특징 추출
= 사람이 특징을 설계

표현학습
= 모델이 데이터로부터 특징을 자동 학습
```

---

# 5. 차원 축소 관점의 특징 추출

특징 추출은 고차원 데이터를 저차원 데이터로 변환하는 **차원 축소(Dimensionality Reduction)** 문제로 볼 수 있다.

대표적인 접근:

- 부분 공간 분석(Subspace Analysis)
- 거리 기반 차원 축소
- 매니폴드 학습

---

# 6. 선형 변환에 의한 특징 추출

선형 변환에서는 고차원 데이터를 **특정 방향으로 사영(Projection)**하여 저차원의 특징값을 얻는다.

예:

```text
2차원 데이터 → 1차원 특징값
3차원 데이터 → 2차원 특징 벡터
n차원 데이터 → m차원 특징 벡터
```

단,

\[
m < n
\]

이다.

입력 데이터 \(x\)를 변환 행렬 \(W\)에 의해 정해지는 방향으로 사영하여 특징 벡터 \(y\)를 얻는다.

\[
y = W^T x
\]

전체 데이터 집합 \(X\)에 대해서는 특징 행렬 \(Y\)를 얻는다.

```text
원본 데이터
→ 변환 행렬 W가 정의하는 방향으로 사영
→ 저차원 특징 벡터
```

---

# 7. PCA와 LDA

대표적인 선형 특징 추출 방법에는 **PCA**와 **LDA**가 있다.

| 구분 | PCA | LDA |
|---|---|---|
| 정식 명칭 | 주성분 분석 | 선형판별분석 |
| 클래스 정보 | 사용하지 않음 | 사용 |
| 학습 유형 | 비지도학습 | 지도학습 |
| 주요 목적 | 데이터의 분산 최대화 | 클래스 간 분리 최대화 |
| 기준 | 전체 데이터의 정보 보존 | 클래스 판별 능력 향상 |

```text
PCA
= 클래스 정보 X
= 비지도학습

LDA
= 클래스 정보 O
= 지도학습
```

---

# 8. 주성분 분석(PCA)

## 8.1 개념

**PCA(Principal Component Analysis)**는 변환 전 데이터가 가지고 있는 정보를 차원 축소 후에도 최대한 유지하도록 하는 변환 행렬 \(W\)를 찾는 방법이다.

핵심 아이디어:

> 데이터의 **분산이 가장 큰 방향**으로 데이터를 사영한다.

분산이 크다는 것은 해당 방향으로 데이터의 변화와 정보가 많이 포함되어 있다는 의미로 볼 수 있다.

---

## 8.2 주성분의 방향

PCA에서는 데이터의 **공분산 행렬(Covariance Matrix)**을 구한 후 고유치 분석을 수행한다.

- 공분산 행렬의 **고유벡터(Eigenvector)**가 사영 방향을 결정
- 해당 고유벡터의 **고유치(Eigenvalue)**가 그 방향에 포함된 분산의 크기를 나타냄
- 고유치가 큰 고유벡터부터 선택

```text
공분산 행렬 계산
→ 고유치와 고유벡터 계산
→ 고유치가 큰 순서대로 정렬
→ 필요한 개수의 고유벡터 선택
→ 변환 행렬 W 구성
```

---

# 9. PCA 알고리즘 수행 단계

일반적인 PCA 수행 과정은 다음과 같다.

1. 입력 데이터 준비
2. 데이터의 평균 계산
3. 평균을 제거하여 데이터 중심화
4. 공분산 행렬 계산
5. 공분산 행렬의 고유치와 고유벡터 계산
6. 고유치를 큰 순서대로 정렬
7. 상위 \(m\)개의 고유벡터 선택
8. 선택한 고유벡터로 변환 행렬 \(W\) 구성
9. 입력 데이터를 저차원 특징 공간으로 사영

```text
데이터 중심화
→ 공분산 행렬
→ 고유치 분석
→ 큰 고유치에 대응하는 고유벡터 선택
→ 차원 축소
```

---

# 10. PCA에서 축소 차원 m의 선택

축소할 차원 \(m\)을 결정할 때는 **유지되는 정보량과 손실되는 정보량**을 고려한다.

고유치가 클수록 해당 주성분이 설명하는 분산의 비율이 크다.

## 기준

- 손실되는 정보량의 비중
- 유지하고 싶은 정보량
- 선택할 고유벡터의 개수

대표적으로 **누적 설명 분산 비율(Cumulative Explained Variance Ratio)**을 이용한다.

예:

```text
전체 정보의 95%를 유지하도록
상위 고유벡터 선택
```

---

# 11. PCA의 특징

- 클래스 정보를 사용하지 않는 **비지도학습**
- 데이터 분산이 큰 방향을 우선적으로 선택
- 데이터 압축과 시각화에 유용
- 특별한 분석 목적이나 클래스 정보가 없는 경우 일반적으로 사용할 수 있는 합리적인 차원 축소 방법
- 선형 변환이므로 복잡한 **비선형 구조를 제대로 반영하지 못할 수 있음**

---

# 12. 선형판별분석(LDA)

## 12.1 개념

**LDA(Linear Discriminant Analysis)**는 클래스 정보를 이용하여 **서로 다른 클래스가 잘 구분되는 방향으로 데이터를 차원 축소**하는 방법이다.

목표:

- 같은 클래스의 데이터는 서로 가깝게
- 다른 클래스의 데이터는 서로 멀리 떨어지도록 변환

```text
클래스 내부
→ 가능한 가깝게

클래스 사이
→ 가능한 멀게
```

---

# 13. LDA의 목적함수

LDA는 다음 두 가지 산점도(Scatter)를 고려한다.

## 클래스 내 산점도

같은 클래스에 속한 데이터가 얼마나 퍼져 있는지를 나타낸다.

```text
클래스 내 산점도
→ 작을수록 좋음
```

## 클래스 간 산점도

서로 다른 클래스의 중심이 얼마나 떨어져 있는지를 나타낸다.

```text
클래스 간 산점도
→ 클수록 좋음
```

따라서 LDA의 목적은 다음과 같다.

```text
클래스 내 산점도 최소화
+
클래스 간 산점도 최대화
```

이를 만족하도록 목적함수를 최대화하는 변환 행렬 \(W\)를 구한다.

---

# 14. 이진 클래스 LDA

클래스가 두 개인 경우에는 두 클래스의 평균 사이의 거리는 크게 만들고, 각 클래스 내부의 분산은 작게 만드는 방향의 기저 벡터 \(W\)를 찾는다.

```text
좋은 사영 방향
= 클래스 간 거리 큼
+ 클래스 내 분산 작음
```

---

# 15. 다중 클래스 LDA

클래스가 여러 개인 경우에도 다음 원칙을 동일하게 사용한다.

- 클래스 내 산점도는 작게
- 클래스 간 산점도는 크게

이 목적함수를 최대화하도록 여러 개의 기저 벡터를 선택하여 변환 행렬을 구성한다.

---

# 16. LDA의 특징과 한계

## 장점

- 클래스 정보를 사용하는 **지도학습**
- 분류 문제에 적합한 특징을 추출할 수 있음
- 클래스 사이의 판별 능력을 높이는 방향으로 차원 축소

## 한계

### 비선형 구조

LDA는 선형 변환이므로 비선형 데이터 구조를 제대로 표현하기 어렵다.

이 경우:

- 매니폴드 학습
- 커널 방법

등을 사용할 수 있다.

### 작은 표본 집합 문제

입력 데이터의 수가 입력 데이터의 차원보다 작은 경우 공분산 또는 산점도 행렬이 특이행렬이 될 수 있다.

```text
표본 수 < 입력 차원
→ Small Sample Size Problem 발생 가능
```

### 선택 가능한 고유벡터 수

LDA는 클래스 수에 따라 선택 가능한 특징 차원의 수에 제한이 있다.

클래스 개수가 \(C\)개라면 일반적으로 최대

\[
C-1
\]

개의 판별 축을 얻을 수 있다.

---

# 17. 거리 기반 차원 축소

거리 기반 차원 축소는 원래 고차원 공간에서의 **데이터 사이의 거리 또는 관계를 저차원에서도 최대한 유지**하도록 차원을 축소하는 방법이다.

거리나 유사도를 어떻게 정의하느냐에 따라 다양한 방법이 존재한다.

대표적인 방법:

- 다차원 척도법(MDS)
- t-SNE
- Isomap

---

# 18. 다차원 척도법(MDS)

**MDS(Multidimensional Scaling)**는 데이터 사이의 거리 정보를 저차원 공간에서도 최대한 유지하도록 데이터를 배치하는 방법이다.

입력:

- 데이터 사이의 거리행렬 \(D\)가 직접 주어지거나
- 원래 입력 데이터로부터 유클리디안 거리 등을 계산

```text
고차원 데이터의 거리 관계
→ 저차원 공간에서도 최대한 유지
```

---

# 19. t-SNE

**t-SNE(t-distributed Stochastic Neighbor Embedding)**는 고차원 데이터와 저차원 특징 데이터에서 데이터 사이의 관계를 **확률적 유사도**로 표현하고, 두 유사도가 비슷해지도록 차원을 축소한다.

## 핵심 아이디어

- 입력 공간: 데이터 사이의 유사도를 **가우시안 분포** 기반의 확률로 표현
- 특징 공간: 데이터 사이의 유사도를 **t-분포**를 이용하여 표현

### 특징

- 가까운 데이터들의 국소적인 구조를 잘 보존
- 복잡한 고차원 데이터를 2차원이나 3차원으로 시각화할 때 많이 사용
- 시각화 결과의 군집 간 절대적인 거리나 크기를 과도하게 해석해서는 안 됨

---

# 20. Isomap

**Isomap(Isometric Mapping)**은 데이터가 놓여 있는 비선형 매니폴드 구조를 고려하기 위해 **측지 거리(Geodesic Distance)**를 사용하는 차원 축소 방법이다.

## 수행 과정

1. 각 데이터를 그래프의 정점으로 표현
2. 가까운 데이터끼리 간선으로 연결
3. 그래프에서 데이터 사이의 최단 경로 계산
4. 최단 경로 길이를 측지 거리로 사용
5. 측지 거리를 최대한 유지하면서 저차원으로 변환

데이터 사이의 최단 경로 계산에는 대표적으로 **데이크스트라 알고리즘**을 사용할 수 있다.

```text
데이터
→ 근접 그래프 생성
→ 최단 경로 계산
→ 측지 거리 계산
→ 저차원 특징 공간 생성
```

> 필기의 `LSOMAP`은 일반적으로 사용하는 알고리즘 명칭인 **Isomap**으로 보는 것이 맞다.

---

# 21. 거리 기반 차원 축소 방법의 특징

- 원래 데이터와 특징 데이터 사이의 **명시적인 매핑 함수를 직접 정의하지 않는 경우가 많음**
- 새 데이터에 대한 즉각적인 변환이 어려운 방법도 있음
- 주로 고차원 데이터의 **시각화와 구조 분석**에 많이 사용
- 비선형 데이터 구조를 표현하는 데 유리한 방법이 존재

---

# 22. PCA vs LDA vs t-SNE vs Isomap

| 구분 | PCA | LDA | t-SNE | Isomap |
|---|---|---|---|---|
| 학습 유형 | 비지도 | 지도 | 비지도 | 비지도 |
| 클래스 정보 | 사용 안 함 | 사용 | 사용 안 함 | 사용 안 함 |
| 변환 | 선형 | 선형 | 비선형 | 비선형 |
| 핵심 기준 | 분산 최대화 | 클래스 판별 최대화 | 확률적 유사도 보존 | 측지 거리 보존 |
| 주요 용도 | 압축, 전처리 | 분류용 특징 추출 | 시각화 | 매니폴드 구조 분석 |

# 23. 시험용 핵심 암기

```text
특징 추출
= 원래 데이터 x
→ 중요한 정보만 추출
→ 새로운 특징 벡터 y
```

```text
차원 축소
= n차원 데이터 → m차원 특징
단, m < n
```

```text
PCA
= 클래스 정보 사용 X
= 비지도학습
= 데이터 분산이 가장 큰 방향
= 공분산 행렬의 고유벡터 사용
```

```text
PCA 수행 과정
= 데이터 중심화
→ 공분산 행렬
→ 고유치/고유벡터
→ 큰 고유치 순으로 선택
→ 저차원 사영
```

```text
LDA
= 클래스 정보 사용 O
= 지도학습
= 클래스 내 산점도 작게
= 클래스 간 산점도 크게
```

```text
PCA vs LDA

PCA
→ 데이터 자체의 정보 보존

LDA
→ 클래스 판별 정보 보존
```

```text
MDS

```

```text
t-SNE

= 특징 공간: t-분포 기반 유사도
= 주로 시각화
```

```text
Isomap

```
