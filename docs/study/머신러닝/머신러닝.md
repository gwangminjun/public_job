# 머신러닝 정리

## 1. 인공지능과 머신러닝

### 인공지능(Artificial Intelligence, AI)

인공지능은 인간의 **학습, 추론, 문제 해결 등의 지능적인 능력을 기계가 수행하도록 만드는 분야**이다.

- **약 인공지능(Weak AI)**
  - 특정 문제를 해결하거나 특정 기능을 수행하는 데 초점
  - 인간처럼 실제로 사고하는지보다는 **행동의 결과**를 중시
- **강 인공지능(Strong AI)**
  - 인간과 같이 스스로 이해하고 사고할 수 있는 지능을 목표로 함

### 머신러닝(Machine Learning)

주어진 데이터를 분석하여 데이터 속의 **일반적인 규칙이나 새로운 지식을 기계가 자동으로 추출하고 학습하는 방법**이다.

#### 머신러닝이 필요한 이유

- 사람이 모든 규칙을 직접 정의하기 어려운 문제를 처리하기 위해 사용
- 다양한 데이터의 변형과 복잡한 패턴을 자동으로 학습하기 위해 사용

### 딥러닝(Deep Learning)

- **심층 신경망(Deep Neural Network)**을 사용하는 머신러닝의 한 분야
- 관계: **인공지능 ⊃ 머신러닝 ⊃ 딥러닝**

---

## 2. 머신러닝 처리 과정

### 학습 단계

```text
학습 데이터 → 데이터 전처리 → 특징 추출 → 학습 → 모델 생성
```

- **학습 데이터**: 모델을 학습시키기 위해 사용하는 데이터
- **데이터 전처리**: 결측치 처리, 정규화, 데이터 변환 등
- **특징 추출**: 분석에 필요한 중요한 정보를 데이터에서 추출
- **학습**: 목적함수의 값을 최적화하도록 모델의 파라미터를 조정

> 전처리는 머신러닝 알고리즘 자체와는 구분되지만, 실제 머신러닝 시스템에서는 매우 중요한 단계이다.

### 추론 단계

```text
새로운 데이터 → 전처리/특징 추출 → 학습된 모델 → 예측 결과
```

대표적인 데이터 분석 문제:

- 분류
- 회귀
- 군집화

---

## 3. 머신러닝에서의 데이터 표현

머신러닝에서는 하나의 데이터를 보통 **특징 벡터(Feature Vector)** 형태로 표현한다.

예:

```text
사람 = [키, 몸무게, 나이]
```

### Flattening

다차원 데이터를 **1차원 벡터 형태로 펼치는 것**이다.

예:

```text
28 × 28 이미지 → 784차원 벡터
```

---

## 4. 특징 추출(Feature Extraction)

원래 데이터로부터 **분석이나 학습에 유용한 특징을 찾아 새로운 데이터 표현으로 변환하는 과정**이다.

대표적인 방법:

- **PCA(주성분 분석)**: 데이터의 정보를 최대한 유지하면서 차원을 축소
- **LDA(선형 판별 분석)**: 서로 다른 클래스가 잘 구분되도록 특징을 추출

---

## 5. 목적함수(Objective Function)

목적함수는 학습을 통해 달성해야 하는 목표를 **기계가 계산할 수 있는 수학적인 함수**로 표현한 것이다.

대표적인 목적함수 중 하나가 **오차 함수(Loss Function)**이다.

### 오차 함수

원하는 출력값과 학습 시스템이 출력한 값의 차이를 수치화한다.

```text
학습의 목적 → 오차 최소화
```

---

## 6. 오차와 성능 평가

- **학습 오차(Training Error)**: 학습에 사용한 데이터에서 측정한 오차
- **테스트 오차(Test Error)**: 학습에 사용하지 않은 테스트 데이터에서 측정한 오차
- **일반화 오차(Generalization Error)**: 모델이 전체 데이터 분포에 대해 보일 것으로 기대되는 오차

### 교차 검증(Cross Validation)

제한된 데이터 집합을 여러 부분으로 나누어 반복적으로 학습과 검증을 수행함으로써 **일반화 성능을 추정하는 방법**이다.

대표적인 방법: **K-Fold Cross Validation**

# 7. 머신러닝의 주요 데이터 분석 문제

## 7.1 분류(Classification)

입력 데이터를 이미 정의된 몇 개의 **클래스(Class)** 중 하나로 구분하는 문제이다.

### 목표

- 각 클래스를 가장 잘 구분하는 **최적의 결정경계(Decision Boundary)**를 찾는 것

### 대표적인 두 가지 접근법

#### ① 확률 기반 방법

- 입력 데이터가 각 클래스에 속할 **조건부 확률**을 이용하여 분류
- 대표 알고리즘: **베이즈 분류기(Bayes Classifier)**

#### ② 데이터 기반 방법

- 학습 데이터 사이의 **거리나 관계**를 이용하여 분류
- 대표 알고리즘:
  - 최근접 이웃 분류기
  - **K-최근접 이웃(K-NN) 분류기**

---

## 7.2 회귀(Regression)

입력 변수와 출력 변수 사이의 **함수 또는 매핑 관계를 찾아 연속적인 값을 예측하는 문제**이다.

예:

- 집값 예측
- 온도 예측
- 매출 예측

---

## 7.3 군집화(Clustering)

정답 정보가 없는 데이터를 **데이터 사이의 유사성에 따라 여러 그룹으로 묶는 문제**이다.

---

# 8. 베이즈 분류기(Bayes Classifier)

## 8.1 개념

주어진 데이터가 각 클래스로부터 생성되었을 **조건부확률(사후확률)**을 계산하고, 그 확률값이 가장 큰 클래스로 분류하는 방법이다.

조건부확률은 학습 데이터를 이용하여 추정한 클래스별 분포함수를 통해 계산하며, 이 과정에서 **베이즈 정리**가 적용된다.

### 처리 과정

```text
학습 데이터 수집
→ 클래스별 분포함수 추정
→ 테스트 데이터 입력
→ 판별함수값 계산
→ 가장 큰 값을 갖는 클래스로 할당
```

### 학습과 분류

- **학습 단계**
  - 모집단에서 데이터 집합 추출
  - 클래스별 확률밀도함수 추정
- **분류 단계**
  - 구해진 확률밀도함수를 이용
  - 베이즈 정리 적용
  - 사후확률이 가장 큰 클래스 선택

---

## 8.2 베이즈 정리

베이즈 정리는 **사전확률로부터 사후확률을 계산하는 방법**이다.

\[
P(C_i|x)=\frac{P(x|C_i)P(C_i)}{P(x)}
\]

### 주요 용어

- **사전확률(Prior Probability, 선험확률)**
  - 데이터를 관찰하기 전에 알고 있는 클래스의 확률
  - \(P(C_i)\)

- **우도(Likelihood)**
  - 특정 클래스에서 데이터 \(x\)가 관찰될 가능성
  - \(P(x|C_i)\)

- **사후확률(Posterior Probability, 후험확률)**
  - 데이터 \(x\)를 관찰한 후 해당 클래스에 속할 확률
  - \(P(C_i|x)\)

### 분류 규칙

입력 데이터 \(x\)에 대해 각 클래스의 사후확률을 계산한 뒤 **가장 큰 사후확률을 갖는 클래스에 할당**한다.

\[
C(x)=\arg\max_i P(C_i|x)
\]

---

## 8.3 이진 분류

클래스가 \(C_1\), \(C_2\) 두 개인 경우:

- \(P(C_1|x) > P(C_2|x)\) 이면 \(C_1\)
- \(P(C_2|x) > P(C_1|x)\) 이면 \(C_2\)

### 우도비(Likelihood Ratio)

각 클래스에서 데이터 \(x\)가 관찰될 확률밀도의 비율이다.

\[
\frac{p(x|C_1)}{p(x|C_2)}
\]

이를 사전확률과 함께 이용하여 어느 클래스로 분류할지 결정할 수 있다.

---

## 8.4 결정경계

결정경계는 **서로 다른 클래스를 구분하는 경계**이다.

### 1차원 데이터 + 이진 클래스

#### 클래스의 전체 비율이 같은 경우

\[
P(C_1)=P(C_2)
\]

- 클래스별 확률밀도를 비교하여 분류 가능

#### 클래스의 전체 비율이 다른 경우

\[
P(C_1)\neq P(C_2)
\]

- 확률밀도뿐 아니라 **사전확률까지 고려**
- 사전확률에 따라 결정경계 위치가 달라질 수 있음

---

## 8.5 다중 클래스 문제

클래스가 여러 개인 경우 각 클래스별 **판별함수(Discriminant Function)**를 계산한다.

\[
g_1(x), g_2(x), \dots, g_k(x)
\]

### 클래스 레이블 결정 규칙

\[
C(x)=\arg\max_i g_i(x)
\]

즉, **판별함숫값이 가장 큰 클래스에 입력 데이터를 할당**한다.

# 9. 가우시안 베이즈 분류기

클래스별 데이터가 **가우시안 분포(정규분포)**를 따른다고 가정하는 베이즈 분류기이다.

분류에 사용되는 주요 정보:

- 클래스별 평균
- 클래스별 공분산 행렬
- 클래스별 사전확률

## 공분산 행렬 형태에 따른 판별 함수

| 공분산 조건 | 분류 방법 |
|---|---|
| 모든 클래스의 공분산이 동일한 단위행렬 | 최소거리 분류기 |
| 모든 클래스의 공분산 행렬이 동일 | 마할라노비스 거리 기반 분류 |
| 클래스마다 공분산 행렬이 다름 | 일반적인 가우시안 베이즈 분류기 |

### 최소거리 분류기

각 클래스의 평균과 입력 데이터 사이의 거리를 계산하여 **가장 가까운 평균을 갖는 클래스로 분류**한다.

주로 유클리디안 거리를 사용한다.

### 마할라노비스 거리

단순 거리뿐 아니라 **데이터의 분산과 변수 사이의 상관관계까지 고려하는 거리**이다.

---

# 10. 최근접 이웃 분류기(Nearest Neighbor)

## 10.1 개념

별도의 확률분포 모델을 사용하지 않고 **주어진 학습 데이터를 직접 이용하여 분류**하는 방법이다.

클래스와 상관없이 모든 학습 데이터 중 입력 데이터와의 거리가 가장 작은 데이터를 찾고, 그 데이터가 속한 클래스로 입력 데이터를 분류한다.

### 1-NN

**K=1인 경우** 가장 가까운 학습 데이터 하나의 클래스로 분류한다.

> 기존 필기의 `k-1인 경우`는 `k=1인 경우`로 보는 것이 맞다.

### 수행 단계

1. 입력 데이터와 모든 학습 데이터 사이의 거리 계산
2. 가장 가까운 데이터 \(x_{min}\)을 찾음
3. \(x_{min}\)이 속한 클래스로 입력 데이터를 할당

### 거리 함수

- 유클리디안 거리
- 코사인 거리
- 마할라노비스 거리

---

# 11. K-최근접 이웃(K-NN)

최근접 이웃을 하나만 사용하는 것이 아니라 **가장 가까운 K개의 학습 데이터**를 이용한다.

### 처리 과정

```text
테스트 데이터 입력
→ 모든 학습 데이터와 거리 계산
→ 가까운 데이터 K개 선택
→ K개의 클래스 확인
→ 가장 많이 등장한 클래스로 분류
```

예를 들어 K=5일 때 가까운 데이터의 클래스가 다음과 같다면:

```text
A, A, B, A, B
```

- A: 3개
- B: 2개

따라서 **A 클래스로 분류**한다.

---

# 12. 가우시안 베이즈 분류기 vs K-NN

| 구분 | 가우시안 베이즈 | K-NN |
|---|---|---|
| 접근 방법 | 확률 기반 | 데이터/거리 기반 |
| 모델 | 확률분포 모델 사용 | 별도 분포 모델 없이 학습 데이터 직접 사용 |
| 학습 | 평균, 분산, 공분산 등을 추정 | 학습 데이터 저장 |
| 분류 기준 | 사후확률 | 가까운 K개 데이터의 클래스 |
| 핵심 요소 | 베이즈 정리 | K값, 거리함수 |
| 예측 속도 | 비교적 빠름 | 학습 데이터가 많으면 느려질 수 있음 |
| 데이터 분포 가정 | 가우시안 등 분포 가정 가능 | 특정 분포 가정이 거의 없음 |

# 13. 학습 유형

## 지도학습(Supervised Learning)

학습할 때 입력 데이터와 함께 **정답(Label 또는 Target)**을 제공한다.

대표 문제:

- 분류
- 회귀

## 비지도학습(Unsupervised Learning)

정답 없이 **입력 데이터 자체의 구조나 패턴을 찾는 학습 방식**이다.

대표 문제:

- 군집화
- 차원 축소

## 강화학습(Reinforcement Learning)

정답 행동을 직접 알려주는 대신 **행동의 결과에 대한 보상(Reward)**을 이용해 학습한다.

---

# 14. 시험용 핵심 암기

```text
분류 = 어떤 종류인가? → 클래스 결정
회귀 = 값이 얼마인가? → 연속값 예측
군집화 = 어떤 것끼리 비슷한가? → 그룹화
```

```text
베이즈 분류기
= 확률분포 학습
→ 베이즈 정리
→ 사후확률이 가장 큰 클래스 선택
```

```text
1-NN
= 가장 가까운 1개의 학습 데이터 클래스 선택
```

```text
K-NN
= 가장 가까운 K개의 학습 데이터 선택
→ 다수결로 클래스 결정
```

```text
공통 단위 공분산 → 최소거리 분류기
공통 공분산 → 마할라노비스 거리 기반 분류
서로 다른 공분산 → 일반적인 가우시안 베이즈 분류기
```

```text
지도학습 = 정답 O → 분류, 회귀
비지도학습 = 정답 X → 군집화
강화학습 = 정답 대신 보상
```
