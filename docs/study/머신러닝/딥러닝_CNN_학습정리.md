# 딥러닝 학습 정리

## 1. 딥러닝

- **딥러닝(Deep Learning)**: 심층 신경망 기반의 머신러닝 분야
- **심층 신경망(Deep Neural Network)**: 많은 층의 은닉층을 가진 MLP
- 복잡한 표현이 가능하지만 학습이 어렵고, 수렴 속도가 느리며, 일반화 성능이 낮아질 수 있다.

---

## 2. 학습 성능 향상 기법

### 2.1 지역 극소(Local Minimum) 문제

- 오차가 충분히 작지 않은 지역 극소에서 학습이 멈추는 문제

#### 해결 기법
- **시뮬레이티드 어닐링(Simulated Annealing, 모의 담금질)**
  - 초기에는 큰 변화를 허용하고 점차 변화 정도를 줄여 지역 극소를 회피한다.
- **확률적 기울기 강하법(SGD, 온라인 학습법)**
  - 한 번에 하나의 학습 샘플을 이용하여 가중치를 갱신한다.
  - 가중치 갱신에 변동성이 생겨 지역 극소나 안장점을 벗어나는 데 도움을 줄 수 있다.

> **암기:** 지역 극소 → 시뮬레이티드 어닐링, SGD

---

### 2.2 느린 학습 문제

#### 원인

##### 플라토(Plateau)
- 오차함수의 학습 곡선에서 기울기가 매우 작고 평평한 구간
- 가중치 변화가 거의 없어 학습 속도가 느려진다.

##### 안장점(Saddle Point)
- 극대점도 극소점도 아닌 극점
- 방향에 따라 함수값이 증가하거나 감소한다.
- 기울기가 매우 작아 학습이 정체될 수 있다.

##### 기울기 소멸(Vanishing Gradient)
- 오류 역전파 과정에서 출력층의 오차 신호가 앞쪽 층으로 전달될수록 기울기가 작아지는 현상
- 가중치 수정 폭이 매우 작아져 학습이 느려지거나 진행되지 않는다.

#### 느린 학습 개선 기법

1. **활성화 함수의 변형**
   - 기울기가 지나치게 작아지지 않는 활성화 함수 사용
   - 예: ReLU, Softplus

2. **가중치 초기화**
   - 입력의 가중합이 적절한 범위에 있도록 초기값을 설정
   - 대표 방법: Xavier 초기화, He 초기화

3. **모멘텀(Momentum)**
   - 현재 기울기뿐 아니라 이전의 가중치 변화 방향을 반영
   - 학습 속도를 높이고 진동을 줄인다.

4. **적응적 학습률(Adaptive Learning Rate)**
   - 가중치마다 서로 다른 학습률을 사용
   - 대표 방법: **RMSProp, Adam**
   - 시험에서 “느린 학습 개선을 위한 적응적 학습률 기법의 하나”라고 나오면 RMSProp 또는 Adam을 기억

5. **배치 정규화(Batch Normalization)**
   - 활성화 함수에 들어가는 데이터를 정규화하여 입력 분포를 안정적으로 유지
   - 학습을 안정화하고 수렴 속도를 개선한다.

6. **2차 미분 방법**
   - 기울기의 변화량을 결정할 때 2차 미분인 곡률 정보를 활용

> **암기:** 느린 학습 → 활성화 함수, 가중치 초기화, 모멘텀, 적응적 학습률, 배치 정규화, 2차 미분

---

### 2.3 과다적합(Overfitting)

- 학습 데이터의 노이즈까지 지나치게 학습하여 새로운 데이터에 대한 정확도와 성능이 떨어지는 현상

#### 해결 기법

1. **조기 종료(Early Stopping)**
   - 검증 오차를 에포크마다 확인하여 학습 종료 시점을 결정

2. **정규항 추가(Regularization)**
   - 오차함수에 정규항을 추가하여 모델의 복잡도를 제한
   - 대표적으로 L1, L2 정규화가 있다.

3. **드롭아웃(Dropout)**
   - 학습 과정에서 가중치를 수정할 때 임의로 선택한 은닉 노드 일부를 제외

4. **데이터 증대(Data Augmentation)**
   - 기존 데이터를 회전, 이동, 확대/축소 등 인위적으로 변형하여 추가 학습 데이터를 생성

> **암기:** 과다적합 → 조기 종료, 정규항 추가, 드롭아웃, 데이터 증대

---

## 3. 대표적인 심층 신경망

### CNN(Convolutional Neural Network)
- **합성곱 신경망**
- 격자 구조를 가진 데이터 처리에 적합
- 대표적으로 영상 데이터 처리에 사용

### RNN(Recurrent Neural Network)
- **순환 신경망**
- 시계열 데이터 처리에 적합
- 예: 음성, 텍스트
- 대표적인 개선 구조: **LSTM, GRU**

---

# 4. 합성곱 신경망(CNN)

## 4.1 주요 신경세포/층

CNN의 주요 구성 요소는 다음과 같다.

1. **콘볼루션층(Convolution Layer)**
2. **서브샘플링층/풀링층(Subsampling / Pooling Layer)**
3. **완전연결층(Fully Connected Layer)**

---

## 4.2 네트워크 구조

### 입력층
- **2차원 격자 구조 × 다중 채널**
- 예: RGB 이미지는 높이 × 너비 × 3채널

### 콘볼루션층과 풀링층
- **2차원 특징맵 × 다중 필터**
- 특징:
  - 부분적인 연결(Local Connectivity)
  - 가중치 공유(Weight Sharing)

### 학습 알고리즘
- **오류 역전파 알고리즘(Backpropagation)** 사용

---

# 5. 콘볼루션층

## 5.1 콘볼루션 연산

- 주어진 입력에 콘볼루션 연산을 반복 적용하여 **특징맵(Feature Map)**을 생성
- 해당 위치의 입력 요소에 필터의 가중치를 곱한 뒤 모두 더하는 연산
- 다양한 형태의 특징을 추출하기 위해 여러 개의 필터를 사용

### 필터의 역할 예시
- 가로선
- 세로선
- 모서리
- 특정 패턴

---

## 5.2 패딩(Padding)

- 입력 데이터의 가장자리를 특정 값으로 채우는 방법
- 대표적으로 가장자리를 **0으로 채우는 Zero Padding** 사용
- 합성곱 연산 후 특징맵의 크기가 지나치게 줄어드는 것을 방지
- 이미지 가장자리 정보도 활용할 수 있도록 한다.
- 필터 크기에 따라 필요한 패딩 크기가 달라진다.

---

## 5.3 보폭(Stride)

- 필터가 한 번에 이동하는 간격
- 보폭이 커질수록 특징맵의 가로·세로 크기는 작아진다.

> **암기:** Padding → 크기 유지에 도움 / Stride → 필터 이동 간격과 출력 크기 조절

---

# 6. 서브샘플링층(풀링층)

## 6.1 개념

- 콘볼루션층의 결과인 **특징맵에 풀링 연산을 적용하여 특징맵을 다운샘플링**한다.
- 특징맵의 가로·세로 크기를 줄여 연산량을 감소시킨다.
- 작은 위치 이동 변화에 대한 민감도를 낮춘다.

---

## 6.2 풀링 연산

- 필터 내 값에 대해 단순 연산을 수행
- 대표적인 방법:
  - **최대 풀링(Max Pooling)**: 영역 내 최댓값 선택
  - **평균 풀링(Average Pooling)**: 영역 내 평균값 계산

### 중요한 특징

- 풀링 연산은 **학습을 통해 결정되는 파라미터가 아니다.**
- 각 특징맵마다 **독립적으로 적용**된다.
- 따라서 풀링 연산 전후의 **특징맵 개수(채널 수)는 변하지 않는다.**
- 대신 특징맵의 **가로·세로 크기만 감소**한다.

예:

```text
28 × 28 × 32
      ↓ Pooling
14 × 14 × 32
```

→ 공간적 크기는 감소하지만 특징맵 수 32개는 그대로 유지

---

## 6.3 사용자 정의 파라미터

풀링층에서 사용자가 지정하는 값:

- 필터 크기
- 보폭(Stride)
- 적용할 풀링 연산
  - 최대 풀링
  - 평균 풀링

> **암기:** Pooling = 크기 감소 / 채널 수 유지 / 학습 파라미터 없음

---

# 7. 시험 핵심 암기

| 느린 학습 개선 | 활성화 함수, 초기화, 모멘텀, 적응적 학습률, 배치 정규화, 2차 미분 |

## 한 줄 암기

- **지역극소 → 어닐링, SGD**
- **느린학습 → 활성화·초기화·모멘텀·적응률·배치정규화·2차미분**
- **과다적합 → 조기종료·정규항·드롭아웃·데이터증대**
- **Pooling → 크기 감소 / 채널 유지 / 학습 파라미터 없음**

# 8. 순차 데이터와 순환 신경망

## 8.1 순차 데이터(Sequential Data)

- **순서 정보를 가진 데이터**
- 데이터가 출현하는 **순서가 중요**
- 데이터의 **길이가 가변적**
- 데이터 요소 사이에 **문맥적·시간적 의존성**이 존재

### 대표적인 순차 데이터
- 음성
- 문장 및 텍스트
- 동영상
- 주식 시세
- 시계열 데이터

> **암기:** 순차 데이터 = 순서 중요 / 길이 가변 / 요소 간 의존성 존재

---

## 8.2 순환 신경망(RNN)

- **시간에 따라 순차적으로 제공되는 데이터를 처리하기 위한 신경망**
- 입력층, 은닉층, 출력층으로 구성되어 전체적인 형태는 MLP와 유사
- 은닉 노드에 **순환 연결(Recurrent Connection)**이 존재
- 직전 시점의 정보를 현재 시점의 계산에 이용

즉,

**현재 입력 + 이전 시점의 정보 → 현재 출력**

의 구조를 가진다.

### 특징
- **가중치 공유**
  - 각 시간 단계에서 동일한 가중치를 반복해서 사용
- **순차적 계산**
  - 이전 시점의 은닉 상태가 다음 시점의 계산에 사용
- 순서와 문맥을 고려할 수 있음

### 주요 응용
- 텍스트 처리
- 음성 처리
- 기계 번역
- 감정 분석
- 동영상 분석
- 시계열 예측

---

# 9. Vanilla RNN

- 가장 기본적인 형태의 순환 신경망
- 기본적으로 하나의 은닉층으로 구성할 수 있으며, 여러 은닉층을 가지는 **다층 RNN**도 가능
- 일반적으로 은닉층에서는 **tanh(하이퍼탄젠트)** 활성화 함수를 많이 사용
- 분류 문제의 출력층에서는 **Softmax** 등을 사용할 수 있음

---

## 9.1 RNN 입력과 출력 구조

RNN은 문제의 목적에 따라 입력과 출력의 대응 관계가 달라질 수 있다.

### 1 : m
**하나의 입력 → 여러 개의 출력**

예:
- 이미지 캡셔닝

### m : 1
**여러 개의 입력 → 하나의 출력**

예:
- 문장 감정 분류
- 온라인 필기 문자 인식

### m : n
**여러 개의 입력 → 여러 개의 출력**

예:
- 기계 번역
- 프레임 수준의 비디오 분류

---

## 9.2 RNN의 확장

### 다층 RNN
- RNN의 은닉층을 여러 층으로 구성
- 더 복잡한 특징을 학습할 수 있음

### 양방향 RNN(Bidirectional RNN)
- 과거 → 미래 방향뿐 아니라
- 미래 → 과거 방향의 정보도 함께 이용

---

# 10. RNN 학습

## 10.1 BPTT

**BPTT(Backpropagation Through Time)**  
= **시간 역전파 알고리즘**

- RNN의 지도학습에 사용
- MLP의 오류 역전파 알고리즘에 **시간성 정보**를 반영하도록 확장한 방법
- 시간에 따라 펼쳐진 RNN에서 오차를 이전 시점으로 역전파하여 가중치를 수정

> **암기:** RNN 학습 → BPTT(시간 역전파)

---

# 11. RNN 학습의 문제

## 11.1 기울기 소멸(Vanishing Gradient)

- 역전파 과정에서 기울기가 반복적으로 곱해지면서 **기하급수적으로 작아져 0에 가까워지는 현상**
- 이전 시점의 정보까지 학습하기 어려워짐
- 오래전 입력의 영향을 제대로 반영하기 어려움
- **장기 의존성(Long-Term Dependency) 문제**와 연결

### 중요
RNN의 기울기 소멸 문제는 단순히 신경망의 층 수뿐 아니라,  
**RNN 계산에 참여하는 시점의 길이(Timestep)가 길어질수록** 심해질 수 있다.

---

## 11.2 기울기 폭발(Exploding Gradient)

- 역전파 과정에서 기울기가 반복적으로 곱해지면서 **기하급수적으로 커지는 현상**
- 가중치가 지나치게 크게 변경되어 학습이 불안정해질 수 있음

> **암기:** RNN 문제 → 기울기 소멸 + 기울기 폭발

---

# 12. 장기 의존성 문제

- RNN은 이전 시점의 정보를 이용하지만 시간 간격이 너무 길어지면
  **오래전의 중요한 정보를 현재 시점까지 전달하기 어려운 문제**가 발생한다.
- 이를 해결하기 위해 등장한 대표적인 구조:
  - **LSTM**
  - **GRU**

> **암기:** 기본 RNN의 기울기 소멸·장기 의존성 문제 → LSTM, GRU

---

# 13. LSTM

## 13.1 개념

**LSTM(Long Short-Term Memory)**

- 기본 RNN의 **장기 의존성 문제를 해결하기 위해 개발된 순환 신경망 셀**
- 셀 상태(Cell State)를 통해 중요한 정보를 오랫동안 유지
- 여러 종류의 **게이트(Gate)**를 이용하여 정보의 흐름을 제어
- 입력과 계산 결과를 선택적으로 반영하여 각 입력값이 영향을 미칠 수 있는 범위를 확장

즉,

**어떤 정보를 기억하고, 어떤 정보를 버리고, 어떤 정보를 출력할지 결정**

한다.

---

## 13.2 LSTM의 3가지 게이트

### ① 망각 게이트(Forget Gate)
- 기존 셀 상태의 정보를 **얼마나 지우고 남길지 결정**

> 기존 정보 중 무엇을 잊을지 결정

### ② 입력 게이트(Input Gate)
- 새로운 정보를 **셀 상태에 얼마나 추가할지 결정**

> 새로운 정보를 얼마나 기억할지 결정

### ③ 출력 게이트(Output Gate)
- 현재 셀 상태를 바탕으로 **얼마나 출력할지 결정**

> 현재 정보를 얼마나 외부로 출력할지 결정

### 암기
- **망각 → 기존 정보 삭제/유지**
- **입력 → 새로운 정보 추가**
- **출력 → 현재 정보 출력**

---

## 13.3 LSTM의 특징

### 장점
- 중요한 정보를 장시간 유지
- 기본 RNN보다 장기 의존성 문제에 강함
- 기울기 소멸 문제를 완화

### 단점
- 구조가 복잡
- 게이트가 많음
- 파라미터 수가 많음
- 계산량이 증가

---

# 14. GRU

## 14.1 개념

**GRU(Gated Recurrent Unit)**

- LSTM의 셀 구조를 **더 단순하게 개선한 순환 신경망 셀**
- 기능적으로 LSTM과 유사
- LSTM처럼 별도의 셀 상태를 두지 않고 **셀 출력/은닉 상태에 통합하여 표현**
- **2개의 게이트** 사용

---

## 14.2 GRU의 2가지 게이트

### ① 리셋 게이트(Reset Gate)
- 이전 시점의 출력을 **현재 계산에 어느 정도 반영할지 조정**

> 이전 정보를 얼마나 사용할지 조절

### ② 갱신 게이트(Update Gate)
- 새로운 정보와 이전 정보를 **어떤 비율로 사용할지 결정**
- LSTM의 입력 게이트와 망각 게이트 기능을 어느 정도 통합

> 이전 정보와 새로운 정보의 비율 조절

---

# 15. RNN · LSTM · GRU 비교

| 구분 | RNN | LSTM | GRU |
|---|---|---|---|
| 구조 | 가장 단순 | 복잡 | LSTM보다 단순 |
| 장기 의존성 | 취약 | 강함 | 강함 |
| 기울기 소멸 | 발생하기 쉬움 | 완화 | 완화 |
| 별도 셀 상태 | 없음 | 있음 | 없음 |
| 게이트 | 없음 | 3개 | 2개 |
| 게이트 종류 | - | 망각·입력·출력 | 리셋·갱신 |
| 파라미터 수 | 적음 | 많음 | LSTM보다 적음 |

---

# 16. RNN 시험 핵심 암기

| 구분 | 핵심 내용 |
|---|---|
| 순차 데이터 | 순서 중요, 길이 가변, 문맥적 의존성 |
| RNN | 이전 시점 정보를 현재 계산에 이용 |
| RNN 특징 | 가중치 공유, 순차적 계산 |
| RNN 학습 | BPTT(시간 역전파) |
| RNN 문제 | 기울기 소멸, 기울기 폭발, 장기 의존성 |
| LSTM | 장기 의존성 문제 완화 |
| LSTM 게이트 | 망각, 입력, 출력 |
| GRU | LSTM을 단순화한 구조 |
| GRU 게이트 | 리셋, 갱신 |
| LSTM 게이트 수 | 3개 |
| GRU 게이트 수 | 2개 |

---

## RNN 한 줄 암기

- **순차 데이터 → 순서·길이·문맥이 중요**
- **RNN → 이전 정보를 현재 계산에 반영**
- **RNN 학습 → BPTT**
- **RNN 문제 → 기울기 소멸·기울기 폭발**
- **LSTM → 장기 기억 + 망각·입력·출력 게이트**
- **GRU → LSTM 단순화 + 리셋·갱신 게이트**
- **LSTM 3개 / GRU 2개**
