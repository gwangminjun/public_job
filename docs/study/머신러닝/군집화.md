# 군집화(Clustering)

## 1. 군집화의 개념

군집화는 **데이터 집합에 내재된 분포 특성을 분석하여 서로 겹치지 않는 여러 부분집합(군집, Cluster)으로 나누는 문제**이다.

- 같은 군집의 데이터는 서로 유사하도록 구성
- 다른 군집의 데이터는 서로 다르도록 구성
- **클래스 레이블이 주어지지 않은 데이터**에 적용
- 대표적인 **비지도학습(Unsupervised Learning)** 문제

---

## 2. 분류 vs 군집화

| 구분 | 분류(Classification) | 군집화(Clustering) |
|---|---|---|
| 클래스 정보 | 있음 | 없음 |
| 학습 유형 | 지도학습 | 비지도학습 |
| 목적 | 미리 정의된 클래스에 데이터 할당 | 데이터 자체의 구조를 분석해 그룹 생성 |
| 정답 레이블 | 필요 | 필요하지 않음 |

```text
분류 = 클래스 정보 O → 지도학습
군집화 = 클래스 정보 X → 비지도학습
```

---

## 3. 군집화 적용 가능 데이터

군집화는 일반적으로 **데이터에 대한 클래스 레이블이 주어지지 않은 경우** 사용한다.

예:
- 고객 구매 패턴 그룹화
- 문서 주제별 그룹화
- 이미지 유사도 기반 그룹화
- 유전자 데이터 분석
- 이상 데이터 탐색

---

# 4. K-평균 군집화(K-Means Clustering)

## 4.1 개념

K-평균은 주어진 데이터 집합을 **평균 정보를 활용하여 K개의 군집으로 묶는 알고리즘**이다.

- 각 군집을 대표하는 **대표 벡터(중심점, Centroid)**를 사용
- 각 데이터는 가장 가까운 중심점이 있는 군집에 할당
- 군집에 속한 데이터의 평균으로 중심점을 다시 계산
- 설정된 반복 횟수에 도달하거나 값의 변화가 거의 없을 때까지 반복

```text
K개의 중심점 설정
→ 가장 가까운 중심점에 데이터 할당
→ 군집별 평균으로 중심점 갱신
→ 반복
```

## 4.2 대표 벡터

군집 C_k의 중심 벡터 μ_k는 해당 군집에 속한 데이터들의 평균이다.

μ_k = (1 / |C_k|) Σ x_i

즉,

```text
군집 중심 = 해당 군집 데이터들의 평균 벡터
```

---

# 5. K-평균의 수행 과정

1. 군집 개수 K를 결정한다.
2. K개의 초기 중심점을 설정한다.
3. 각 데이터를 가장 가까운 중심점의 군집에 할당한다.
4. 각 군집의 평균을 계산하여 중심점을 갱신한다.
5. 종료 조건을 만족할 때까지 3~4단계를 반복한다.

### 종료 조건

- 설정한 최대 반복 횟수에 도달
- 중심점의 변화가 없음
- 군집 구성이 더 이상 변하지 않음

---

# 6. K-평균의 목적함수

K-평균은 각 데이터와 해당 군집 중심 사이의 **거리 제곱합을 최소화**하는 것을 목표로 한다.

J = Σ Σ ||x_i - μ_k||²

### 반복 수행의 의미

- 한 번 반복할 때마다 목적함수 값이 **증가하지 않고 감소하는 방향**으로 진행된다.
- 따라서 일정 횟수 반복하면 수렴한다.
- 다만 초기 중심값에 따라 **지역 최적해(Local Optimum)**에 수렴할 수 있다.

---

# 7. K-평균의 특징과 문제점

## 초기값 의존성

- 처음 설정한 중심점에 따라 최종 군집 결과가 달라질 수 있다.
- 이를 완화하기 위해 **K-Means++** 같은 초기화 방법을 사용할 수 있다.

## K값에 따른 변화

- K가 너무 작으면 서로 다른 데이터가 하나의 군집에 섞일 수 있다.
- K가 너무 크면 하나의 자연스러운 군집이 여러 개로 나뉠 수 있다.
- 따라서 적절한 K의 선정은 **문제와 데이터 특성에 크게 의존**한다.

대표적인 K 선정 방법:
- 엘보우 방법(Elbow Method)
- 실루엣 계수(Silhouette Score)

# 8. 계층적 군집화(Hierarchical Clustering)

계층적 군집화는 전체 데이터를 몇 개의 독립적인 그룹으로만 나누는 것이 아니라, **큰 군집과 작은 군집이 포함 관계를 이루는 계층 구조**로 군집화하는 방법이다.

결과는 일반적으로 **덴드로그램(Dendrogram)**으로 표현한다.

## 방법 구분

### 1. 병합적 방법(Agglomerative)

각 데이터를 하나의 군집으로 시작하여 **가까운 군집끼리 차례대로 병합**한다.

```text
작은 군집 → 큰 군집
Bottom-Up
```

### 2. 분할적 방법(Divisive)

전체 데이터를 하나의 군집으로 시작하여 **큰 군집을 작은 군집으로 계속 분할**한다.

```text
큰 군집 → 작은 군집
Top-Down
```

---

# 9. 군집 간 거리 계산법(Linkage)

계층적 군집화에서는 어떤 군집끼리 합칠지 결정하기 위해 군집 사이의 거리를 계산한다.

## 9.1 최단 연결법(Single Linkage)

두 군집에 속한 데이터 중 **가장 가까운 두 데이터 사이의 거리**를 사용한다.

```text
군집 간 거리 = 최소 거리
```

- 길게 이어지는 군집이 만들어질 수 있음
- 체이닝 현상이 발생할 수 있음

## 9.2 최장 연결법(Complete Linkage)

두 군집에 속한 데이터 중 **가장 멀리 떨어진 두 데이터 사이의 거리**를 사용한다.

```text
군집 간 거리 = 최대 거리
```

- 비교적 조밀한 군집을 만드는 경향

## 9.3 중심 연결법(Centroid Linkage)

각 군집의 **중심점 사이의 거리**를 사용한다.

```text
군집 간 거리 = 두 군집 중심 사이의 거리
```

## 9.4 평균 연결법(Average Linkage)

두 군집에 속한 **모든 데이터 쌍의 거리 평균**을 사용한다.

```text
군집 간 거리 = 모든 데이터 쌍 거리의 평균
```

## 9.5 Ward 방법(Ward's Method)

두 군집을 합쳤을 때 발생하는 **군집 내부 제곱오차 증가량이 가장 작은 두 군집을 병합**한다.

```text
Ward 방법
= 병합 후 군집 내부 오차 증가량 최소
```

- 군집 내부 분산을 작게 유지하는 방향으로 병합
- 비교적 균일한 군집을 만드는 경향

---

# 10. K-평균 vs 계층적 군집화

| 구분 | K-평균 | 계층적 군집화 |
|---|---|---|
| 군집 구조 | K개의 독립된 군집 | 계층 구조 |
| K 지정 | 사전에 필요 | 반드시 사전에 정할 필요 없음 |
| 핵심 기준 | 중심점과의 거리 | 군집 간 거리 |
| 결과 표현 | K개의 군집 | 덴드로그램 |
| 초기값 영향 | 있음 | 상대적으로 적음 |
| 대규모 데이터 | 비교적 적합 | 계산량이 커질 수 있음 |
