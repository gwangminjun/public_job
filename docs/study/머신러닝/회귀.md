# 회귀(Regression)

## 1. 회귀의 개념

회귀는 **입력변수(독립변수)**와 **출력변수(종속변수)** 사이의 매핑 관계를 찾아 새로운 입력에 대한 **연속적인 값**을 예측하는 방법이다.

- 입력변수: 예측에 사용하는 값
- 출력변수: 예측하려는 값
- 대표 예시
  - 집값 예측
  - 온도 예측
  - 매출 예측
  - 시계열 예측

### 회귀의 목표

- 실제값과 예측값의 차이인 **예측 오차를 최소화하는 최적의 회귀함수**를 찾는 것
- 데이터의 전반적인 경향을 가장 잘 설명하는 직선 또는 곡선을 찾는 것

---

## 2. 최소자승법(최소제곱법)

**최소자승법(Least Squares Method)**은 실제값과 예측값의 차이인 **잔차(Residual)**의 제곱합을 최소화하도록 회귀함수를 결정하는 방법이다.

잔차는 다음과 같다.

\[
e_i = y_i - \hat{y}_i
\]

잔차를 그대로 더하면 양수와 음수가 서로 상쇄될 수 있으므로 일반적으로 잔차의 제곱을 사용한다.

\[
SSE = \sum_{i=1}^{n}(y_i-\hat{y}_i)^2
\]

즉,

```text
최소자승법 = 잔차 제곱합이 가장 작아지도록 회귀함수를 결정
```

# 3. 선형회귀(Linear Regression)

## 3.1 개념

선형회귀는 데이터 집합의 입력과 출력 관계를 설명할 수 있는 **선형함수**를 찾는 방법이다.

단순 선형회귀의 기본 형태는 다음과 같다.

\[
\hat{y}=wx+b
\]

- \(x\): 입력값
- \(\hat{y}\): 예측값
- \(w\): 기울기(가중치)
- \(b\): 절편

선형회귀의 학습은 **가장 적절한 기울기와 절편을 찾는 과정**이다.

---

## 3.2 잔차(Residual)

잔차는 실제 출력값과 회귀모델이 예측한 값의 차이이다.

\[
e_i=y_i-\hat{y}_i
\]

좋은 선형회귀 모델은 전체 데이터에 대한 잔차가 가능한 한 작아야 한다.

> 잔차의 단순 합이 아니라 일반적으로 **잔차 제곱합**을 이용하여 모델을 평가하고 학습한다.

---

## 3.3 오차함수와 매개변수 추정

선형회귀에서는 오차함수가 최소가 되도록 매개변수 \(w\), \(b\)를 결정한다.

대표적인 오차함수는 평균제곱오차(MSE)이다.

\[
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
\]

오차함수를 최소화하는 매개변수를 구하는 방법 중 하나는 다음과 같다.

1. 오차함수를 각 매개변수에 대해 **편미분**한다.
2. 편미분 결과가 0이 되는 지점을 찾는다.
3. 해당 지점의 매개변수를 최적의 값으로 사용한다.

```text
선형회귀 학습 목표
= 오차함수가 최소가 되는 기울기와 절편을 찾는 것
```

---

# 4. 회귀 모델의 성능 평가

## 4.1 평균제곱오차(MSE)

**Mean Squared Error**

\[
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
\]

- 실제값과 예측값의 차이를 제곱한 뒤 평균을 계산
- 값이 작을수록 예측 오차가 작은 모델
- 큰 오차에 더 큰 패널티를 부여

---

## 4.2 평균제곱근오차(RMSE)

**Root Mean Squared Error**

\[
RMSE=\sqrt{MSE}
\]

- MSE에 제곱근을 적용한 값
- 출력값과 동일한 단위를 가지므로 해석하기 쉽다.
- 값이 작을수록 좋은 모델이다.

---

# 5. 다변량 선형회귀(Multiple Linear Regression)

다변량 선형회귀는 **여러 개의 입력변수를 이용하여 하나의 출력값을 예측**하는 방법이다.

예를 들어 주택가격을 예측할 때 다음과 같은 여러 입력변수를 사용할 수 있다.

- 주택 면적
- 방 개수
- 건축 연도
- 지하철역과의 거리

회귀식은 다음과 같이 표현할 수 있다.

\[
\hat{y}=w_0+w_1x_1+w_2x_2+\cdots+w_dx_d
\]

행렬 형태로 표현하면 다음과 같다.

\[
\hat{y}=Xw
\]

### 학습 과정

1. 여러 입력변수를 행렬 형태로 표현
2. 오차함수 정의
3. 오차함수를 최소화하는 최적의 파라미터 \(w\) 추정
4. 학습된 파라미터를 이용하여 새로운 데이터의 출력값 예측

---

# 6. 로지스틱 회귀(Logistic Regression)

## 6.1 개념

로지스틱 회귀는 이름에 **회귀**가 포함되어 있지만 실제로는 주로 **분류 문제**에 사용된다.

- 선형회귀의 출력을 그대로 사용하지 않고 **로지스틱 함수(시그모이드 함수)**에 입력
- 최종 결과를 **0~1 사이의 확률값**으로 변환
- 이 확률을 기준으로 클래스를 결정

대표적인 예:

- 스팸 / 정상 메일 분류
- 질병 있음 / 없음 분류
- 정상 거래 / 이상 거래 분류

---

## 6.2 로지스틱 함수(시그모이드 함수)

로지스틱 함수는 S자 형태를 갖는 함수이다.

\[
\sigma(z)=\frac{1}{1+e^{-z}}
\]

선형함수

\[
z=w^Tx+b
\]

를 로지스틱 함수에 적용하면 다음과 같다.

\[
P(y=1|x)=\sigma(w^Tx+b)
\]

### 특징

- 출력값의 범위: **0~1**
- 출력값을 특정 클래스에 속할 확률로 해석할 수 있음
- 선형함수의 파라미터에 따라 로지스틱 함수의 형태가 달라짐

```text
입력
→ 선형함수
→ 시그모이드 함수
→ 0~1 사이의 확률
→ 클래스 결정
```

---

# 7. 오즈(Odds, 승산)

오즈는 어떤 사건이 **발생할 확률과 발생하지 않을 확률의 비율**이다.

사건이 발생할 확률을 \(p\)라고 하면 다음과 같다.

\[
Odds=\frac{p}{1-p}
\]

예를 들어 사건이 발생할 확률이 0.8이라면

\[
Odds=\frac{0.8}{0.2}=4
\]

즉, 사건이 발생할 가능성이 발생하지 않을 가능성보다 4배라는 의미이다.

---

# 8. 로짓 함수(Logit Function)

로짓 함수는 **오즈에 로그를 취한 함수**이다.

\[
logit(p)=\log\frac{p}{1-p}
\]

로지스틱 회귀에서는 로짓과 입력변수 사이의 관계를 선형으로 표현한다.

\[
\log\frac{p}{1-p}=w^Tx+b
\]

즉, 로지스틱 회귀에서는 입력변수와 확률 자체의 관계가 아니라 **확률의 오즈에 로그를 취한 값과 입력변수 사이의 선형 관계**를 학습한다.

---

# 9. 로지스틱 회귀의 매개변수 추정

선형회귀에서는 주로 **최소제곱법**을 사용할 수 있지만, 로지스틱 회귀에서는 새로운 목적함수가 필요하다.

## 9.1 베르누이 분포

이진분류 문제에서는 출력값이 다음과 같다.

\[
y\in\{0,1\}
\]

따라서 하나의 데이터에 대한 확률을 베르누이 분포로 표현할 수 있다.

\[
P(y|x)=p^y(1-p)^{1-y}
\]

---

## 9.2 최대우도추정(MLE)

**Maximum Likelihood Estimation**

최대우도추정은 **현재 관측된 학습 데이터가 발생할 가능성을 가장 크게 만드는 매개변수**를 찾는 방법이다.

즉,

```text
최대우도추정
= 학습 데이터가 관측될 확률(우도)을 최대화하는 파라미터를 찾는 것
```

실제 계산에서는 여러 확률의 곱을 다루기 쉽게 하기 위해 **로그우도(Log-Likelihood)**를 사용한다.

이를 손실함수 형태로 표현하면 대표적으로 **이진 교차 엔트로피(Binary Cross Entropy)**가 된다.

\[
L=-\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]
\]

따라서 로지스틱 회귀의 학습 목표는 다음과 같이 볼 수 있다.

```text
우도를 최대화
= 로그우도를 최대화
= 음의 로그우도(교차 엔트로피)를 최소화
```

# 10. 선형회귀와 로지스틱 회귀 비교

| 구분 | 선형회귀 | 로지스틱 회귀 |
|---|---|---|
| 주요 목적 | 연속적인 값 예측 | 클래스 분류 |
| 출력값 | 연속값 | 0~1 사이의 확률 |
| 대표 예시 | 집값 예측 | 스팸 여부 분류 |
| 기본 구조 | 선형함수 | 선형함수 + 시그모이드 |
| 대표 학습 방법 | 최소제곱법 | 최대우도추정 |
| 대표 손실함수 | MSE | Binary Cross Entropy |
