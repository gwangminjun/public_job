# 선형분류기, SVM, 커널법

## 1. 선형분류기(Linear Classifier)

### 개념
- **선형 판별 함수(Linear Discriminant Function)** 를 기반으로 분류를 수행하는 학습 시스템
- 입력 공간을 **직선, 평면, 초평면(Hyperplane)** 형태의 결정경계로 나누어 클래스를 구분함
- 구조가 단순하여 **분류 시스템의 복잡도가 낮고 계산이 빠른 편**
- 모델이 단순하기 때문에 복잡한 데이터에서는 분류 성능이 제한될 수 있음
- 반대로 모델 복잡도가 낮아 **과다적합(Overfitting)이 발생할 가능성이 비교적 낮음**

### 결정경계

2차원에서는 직선, 3차원에서는 평면, 더 높은 차원에서는 초평면으로 데이터를 나눈다.

```text
Class A      |      Class B
● ● ●        |        ○ ○
 ● ●         |       ○ ○ ○
-------------|-------------
        결정경계
```

### 핵심

```text
선형분류기
= 선형 판별 함수
+ 선형 결정경계

장점 → 구조가 단순하고 계산량이 적음
단점 → 비선형적으로 섞인 데이터에는 한계
```

---

# 2. SVM(Support Vector Machine)

## 개념

SVM은 **여러 개의 가능한 선형 결정경계 중 일반화 성능이 좋은 결정경계를 찾도록 설계된 분류기**이다.

SVM에서는 단순히 학습 데이터를 정확하게 나누는 것만 고려하지 않고, **클래스 사이의 여유 공간인 마진(Margin)을 최대화**하는 결정경계를 찾는다.

```text
일반화 오차를 줄이기 위해
→ 클래스 사이의 간격을 크게
→ 마진을 최대화
```

이를 **최대 마진 분류기(Maximum Margin Classifier)** 라고 한다.

---

# 3. 마진(Margin)

## 개념

**학습 데이터 중 결정경계에 가장 가까운 데이터로부터 결정경계까지의 거리**

즉, 결정경계와 가장 가까운 데이터 사이의 여유 공간이다.

```text
Class A                 Class B

●
  ●       │ Margin │       ○
    ●     │        │     ○
---------- 결정경계 ----------
    ●     │        │     ○
  ●       │ Margin │       ○
```

### 특징

```text
마진이 작음
→ 결정경계가 학습 데이터에 가까움
→ 새로운 데이터에 민감할 가능성 증가

마진이 큼
→ 두 클래스 사이에 충분한 여유 공간 확보
→ 일반화 성능 향상을 기대할 수 있음
```

### SVM의 목표

> **마진을 최대화하는 결정경계를 찾는 것**

---

# 4. 서포트 벡터(Support Vector)

## 개념

**결정경계에 가장 가까운 위치에 있는 학습 데이터**

이 데이터들이 마진의 크기와 결정경계의 위치를 결정한다.

```text
●       ●
    ★               ★
--------- 결정경계 ---------
    ☆               ☆
○       ○

★, ☆ = Support Vector
```

### 핵심

- 결정경계에서 멀리 떨어진 데이터보다 **서포트 벡터가 결정경계 형성에 중요한 역할**을 함
- 학습이 끝난 후 결정경계를 표현하는 데 핵심적인 데이터는 서포트 벡터임

```text
서포트 벡터
→ 결정경계와 가장 가까운 데이터
→ 마진을 결정
→ 최종 결정경계에 직접적인 영향을 줌
```

---

# 5. SVM의 학습 원리

선형적으로 완벽하게 분리할 수 있는 데이터에서는 다음과 같이 생각할 수 있다.

```text
가능한 결정경계 1
가능한 결정경계 2
가능한 결정경계 3
      ↓
각 결정경계의 마진 비교
      ↓
마진이 가장 큰 결정경계 선택
```

즉,

```text
일반화 성능 향상
      ↓
마진을 크게 설정
      ↓
최대 마진 결정경계 선택
```

---

# 6. SVM은 기본적으로 이진 분류기

SVM은 기본적으로 **두 개의 클래스를 구분하는 이진 분류(Binary Classification)** 문제를 대상으로 한다.

```text
Class A
vs
Class B
```

여러 클래스를 분류해야 하는 경우에는 여러 개의 SVM을 조합하는 방식을 사용할 수 있다.

대표적인 방법:

- One-vs-Rest
- One-vs-One

---

# 7. 선형 분리가 불가능한 경우

## 문제

현실의 데이터는 항상 하나의 직선이나 평면으로 완벽하게 분리되지 않는다.

```text
● ● ○ ●
○ ● ● ○
● ○ ○ ●
```

모든 데이터를 완벽하게 분리하도록 강제하면 좋은 결정경계를 찾기 어려울 수 있다.

이를 해결하기 위해 **슬랙 변수(Slack Variable)** 를 사용한다.

---

# 8. 슬랙 변수(Slack Variable)

## 개념

일부 학습 데이터가 **마진 내부에 들어오거나 잘못 분류되는 것을 어느 정도 허용하기 위한 변수**

즉, 모든 데이터를 완벽하게 분류하는 것보다 일정 수준의 오류를 허용하면서 더 좋은 일반화 성능을 얻도록 한다.

```text
완벽한 분류만 허용
→ 경계가 지나치게 복잡해질 수 있음

일부 오류 허용
→ 더 넓은 마진 확보 가능
→ 일반화 성능 향상을 기대
```

슬랙 변수를 사용하는 SVM을 일반적으로 **소프트 마진 SVM(Soft-Margin SVM)** 이라고 한다.

---

# 9. 하드 마진과 소프트 마진

| 구분 | 하드 마진(Hard Margin) | 소프트 마진(Soft Margin) |
|---|---|---|
| 오분류 | 허용하지 않음 | 일부 허용 |
| 적용 데이터 | 완벽하게 선형 분리 가능한 데이터 | 선형 분리가 완벽하지 않은 데이터 |
| 마진 | 데이터 제약을 모두 만족해야 함 | 일부 위반을 허용하며 마진 조정 |
| 핵심 요소 | 최대 마진 | 최대 마진 + 슬랙 변수 |

### 시험 핵심

```text
선형 분리 가능
→ Hard Margin

선형 분리 완벽하지 않음
→ Slack Variable
→ Soft Margin
```

---

# 10. 비선형 분류 문제

다음과 같이 데이터가 구성되어 있다면 하나의 직선으로 분류하기 어렵다.

```text
○ ○ ○ ○ ○
○ ● ● ● ○
○ ● ○ ● ○
○ ● ● ● ○
○ ○ ○ ○ ○
```

이러한 문제를 **비선형 분류 문제**라고 한다.

이를 해결하는 대표적인 방법은 입력 데이터를 **더 높은 차원의 공간으로 변환**하는 것이다.

---

# 11. 고차원 공간으로 매핑

## 개념

저차원의 입력 데이터 `x`를 고차원의 특징 공간(Feature Space)으로 변환한다.

```text
저차원 공간
x
↓
매핑 함수 Φ(x)
↓
고차원 특징 공간
Φ(x)
```

저차원 공간에서는 선형적으로 분리되지 않던 데이터가 고차원 공간에서는 선형적으로 분리될 수 있다.

```text
저차원
→ 비선형 분리 문제

고차원으로 변환
→ 선형 분리 가능

고차원 공간에서
→ 선형분류기 사용 가능
```

---

# 12. 고차원 매핑의 문제점

데이터를 실제로 매우 높은 차원으로 변환하면 다음과 같은 문제가 생길 수 있다.

- 계산량 증가
- 메모리 사용량 증가
- 고차원 특징을 직접 계산해야 함
- 차원이 매우 높거나 무한 차원인 경우 직접 계산이 어려움

이러한 문제를 해결하기 위해 **커널법(Kernel Method)** 을 사용한다.

---

# 13. 커널법(Kernel Method)

## 개념

입력 데이터를 고차원으로 직접 변환하지 않고, **고차원 공간에서 계산한 것과 같은 효과를 주는 커널 함수(Kernel Function)** 를 사용하는 방법이다.

즉,

```text
기존 방법

x
↓
Φ(x)로 실제 변환
↓
고차원에서 계산


커널법

x
↓
Kernel Function
↓
고차원에서 계산한 효과를 직접 얻음
```

이를 **커널 트릭(Kernel Trick)** 이라고 한다.

---

# 14. 커널 함수(Kernel Function)

두 입력 데이터 `x`, `z`에 대해 고차원 특징 공간에서의 내적을 직접 계산하지 않고 커널 함수로 계산한다.

```text
K(x, z)
= 고차원 특징 공간에서의 내적에 해당하는 값
```

즉,

```text
고차원 매핑 Φ(x), Φ(z)를 직접 계산하지 않음
          ↓
커널 함수 K(x, z) 사용
          ↓
계산량을 줄이면서 비선형 분류 가능
```

---

# 15. 대표적인 커널 함수

### 선형 커널(Linear Kernel)

원래 입력 공간에서 선형 분류를 수행할 때 사용한다.

```text
선형적으로 분리가 가능한 데이터에 적합
```

### 다항식 커널(Polynomial Kernel)

다항식 형태의 비선형 관계를 표현할 수 있다.

### RBF 커널(Radial Basis Function Kernel)

복잡한 비선형 결정경계를 표현할 수 있어 SVM에서 자주 사용되는 대표적인 커널이다.

---

# 16. SVM과 커널법의 관계

```text
[선형 분리 가능]

입력 데이터
   ↓
선형 SVM
   ↓
최대 마진 결정경계


[선형 분리 어려움]

입력 데이터
   ↓
커널 함수
   ↓
고차원 공간에서 계산한 효과
   ↓
선형적으로 분리
   ↓
SVM 적용
```

즉,

> **커널법을 이용하면 비선형 데이터도 고차원 공간에서 선형적으로 분류하는 것과 같은 효과를 얻을 수 있다.**

---

# 17. 선형분류기 vs SVM

| 구분 | 일반 선형분류기 | SVM |
|---|---|---|
| 결정경계 | 선형 | 기본적으로 선형 |
| 핵심 목표 | 데이터를 분류 | 마진을 최대화하는 결정경계 탐색 |
| 경계 결정 | 전체 학습 결과에 따라 결정 | 서포트 벡터가 핵심 역할 |
| 일반화 | 단순 모델이므로 비교적 안정적 | 최대 마진을 통해 일반화 성능 향상 추구 |
| 비선형 문제 | 직접 처리하기 어려움 | 커널법을 이용하여 처리 가능 |

---

# 18. 전체 흐름

```text
선형분류기
│
├─ 선형 판별 함수 사용
├─ 구조가 단순함
└─ 비선형 문제에는 한계
        ↓
       SVM
        │
        ├─ 최대 마진 분류기
        ├─ Support Vector
        ├─ Margin 최대화
        └─ 기본적으로 이진 분류
                ↓
      선형 분리가 어려운 경우
                │
                ├─ 일부 오류 존재
                │      ↓
                │   Slack Variable
                │      ↓
                │   Soft Margin SVM
                │
                └─ 비선형 데이터
                       ↓
                 고차원으로 매핑
                       ↓
                  계산량 증가
                       ↓
                    커널법
                       ↓
                   Kernel Trick
```

# 19. 시험 직전 암기 포인트

## 선형분류기

```text
선형 판별 함수 기반
결정경계 → 직선 / 평면 / 초평면
복잡도가 낮음
비선형 데이터에는 한계
```

## SVM

```text
SVM = 최대 마진 분류기

Margin
→ 결정경계와 가장 가까운 학습 데이터 사이의 거리

Support Vector
→ 결정경계에 가장 가까운 데이터

목표
→ Margin 최대화
→ 일반화 성능 향상
```

## 슬랙 변수

```text
선형 분리가 완벽하지 않을 때 사용
일부 데이터의 마진 위반 / 오분류 허용
→ Soft Margin SVM
```

## 커널법

```text
비선형 분류 문제 해결

저차원 데이터
→ 고차원 공간으로 변환하면 선형 분리 가능

하지만
→ 직접 고차원 계산은 부담

따라서
→ Kernel Function 사용
→ 고차원 매핑을 직접 계산하지 않고 같은 효과
```

# 20. 자주 헷갈리는 부분

### ① 마진과 서포트 벡터

```text
Margin
= 결정경계와 가장 가까운 데이터까지의 거리

Support Vector
= 그 가장 가까운 데이터
```

### ② SVM의 핵심

```text
단순히 분류 성공이 목표 X

마진을 최대화하는
결정경계를 찾는 것이 핵심
```

### ③ 슬랙 변수의 목적

```text
비선형을 직접 해결하는 변수 X

일부 마진 위반과 오분류를 허용
→ 선형 분리가 완벽하지 않은 데이터 처리
```

### ④ 커널법의 목적

```text
비선형 문제를
고차원 특징 공간에서
선형적으로 처리할 수 있도록 함
```
