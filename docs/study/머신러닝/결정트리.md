# 결정트리와 랜덤 포레스트

## 1. 결정트리(Decision Tree)

### 개념
- **주어진 입력에 대해 결정을 내리는 함수를 트리(Tree) 형태로 표현한 모델**
- 분류(Classification)와 회귀(Regression) 문제에 모두 사용할 수 있음
- 사람이 판단 과정을 따라가기 쉬워 **설명력과 해석력이 뛰어남**
- 학습 데이터에 지나치게 맞춰지면 **과다적합(Overfitting)** 이 발생하기 쉬움

### 결정트리의 구성

| 구성 요소 | 의미 |
|---|---|
| 루트 노드(Root Node) | 트리의 시작점 |
| 내부 노드(Internal Node) | 속성에 대한 조건을 검사하는 노드 |
| 가지(Branch) | 조건에 따른 분기 |
| 리프 노드(Leaf Node) | 최종 예측 결과를 나타내는 노드 |
| 속성(Feature) | 판단을 내리는 데 사용하는 결정 요인 |

---

## 2. 결정트리와 규칙 기반 표현

결정트리는 **IF-THEN 규칙**의 집합으로 표현할 수 있다.

예를 들어 다음과 같은 결정트리가 있다고 하자.

```text
날씨가 맑은가?
├─ Yes → 기온이 높은가?
│          ├─ Yes → 외출 안 함
│          └─ No  → 외출
└─ No → 외출 안 함
```

이를 규칙으로 표현하면 다음과 같다.

```text
IF 날씨 = 맑음 AND 기온 = 높음 THEN 외출 안 함
IF 날씨 = 맑음 AND 기온 != 높음 THEN 외출
IF 날씨 != 맑음 THEN 외출 안 함
```

즉, **루트 노드에서 리프 노드까지의 하나의 경로가 하나의 규칙**에 해당한다.

---

## 3. 결정트리의 학습

결정트리 학습의 핵심은 다음과 같다.

> **각 노드에 어떤 속성(Feature)을 배정하여 데이터를 분할할 것인가?**

좋은 속성은 데이터를 분할했을 때 **자식 노드의 데이터가 가능한 한 동질적(Pure)** 이 되도록 만드는 속성이다.

이를 판단하기 위해 여러 가지 **속성 선택 평가 기준**을 사용한다.

---

# 4. 속성 선택을 위한 평가 기준

## 4.1 지니 불순도(Gini Impurity)

### 개념
- 하나의 노드 안에 **서로 다른 클래스가 얼마나 섞여 있는지** 측정하는 값
- 클래스가 많이 혼합되어 있을수록 지니 불순도가 높아짐
- 하나의 클래스만 존재하면 지니 불순도는 **0**

### 공식

클래스가 \(K\)개일 때:

```text
Gini(D) = 1 - Σ p(k)^2
```

- `p(k)` : 데이터 집합 D에서 클래스 k가 차지하는 비율

### 예시

노드에 데이터가 다음과 같이 존재한다고 하자.

```text
A 클래스 : 5개
B 클래스 : 5개
```

```text
Gini = 1 - (0.5² + 0.5²)
     = 0.5
```

반대로 모든 데이터가 A 클래스라면:

```text
Gini = 1 - 1²
     = 0
```

따라서:

```text
지니 불순도 ↓ → 데이터가 동질적
지니 불순도 ↑ → 여러 클래스가 혼합됨
```

---

## 4.2 지니 평가지수(Gini Index)

부모 노드를 특정 속성으로 분할했을 때 만들어진 **자식 노드들의 지니 불순도를 가중 평균한 값**이다.

```text
Gini Index
= Σ (자식 노드 데이터 수 / 전체 데이터 수)
    × 자식 노드의 Gini
```

### 속성 선택

```text
지니 평가지수가 작은 속성
→ 자식 노드의 불순도가 작음
→ 좋은 분할
```

즉, 일반적으로 **지니 평가지수가 가장 작은 분할**을 선택한다.

---

# 5. 엔트로피와 정보이득

## 5.1 엔트로피(Entropy)

- 데이터 집합의 **불확실성 또는 혼잡도**를 나타내는 값
- 클래스가 고르게 섞여 있을수록 엔트로피가 큼
- 하나의 클래스만 존재하면 엔트로피는 0

### 공식

```text
Entropy(D) = - Σ p(k) log₂ p(k)
```

---

## 5.2 정보이득(Information Gain)

**분할하기 전 엔트로피와 분할한 후 엔트로피의 차이**이다.

```text
정보이득
= 부모 노드의 엔트로피
  - 자식 노드 엔트로피의 가중합
```

### 의미

```text
정보이득 ↑
→ 분할 후 불확실성이 많이 감소
→ 좋은 속성
```

따라서 일반적으로 **정보이득이 가장 큰 속성**을 선택한다.

> 엔트로피와 정보이득이 단순히 수학적으로 항상 반비례하는 것은 아니다.  
> 중요한 것은 **분할을 통해 엔트로피가 많이 감소할수록 정보이득이 커진다**는 점이다.

# 6. 분산 감소량(Variance Reduction)

### 개념
- 주로 **회귀(Regression) 결정트리**에서 사용하는 평가 기준
- 데이터 값들이 얼마나 흩어져 있는지를 나타내는 **분산(Variance)** 을 이용

분산이 작다는 것은 데이터 값들이 서로 비슷하다는 의미이다.

```text
모든 데이터 값이 동일
→ 분산 = 0
```

### 분할 후 분산

```text
자식 노드 분산의 가중 평균
= Σ (자식 노드 데이터 수 / 전체 데이터 수)
    × 자식 노드의 분산
```

### 분산 감소량

```text
분산 감소량
= 부모 노드의 분산
  - 자식 노드 분산의 가중 평균
```

```text
분산 감소량 ↑
→ 자식 노드의 데이터가 더 동질적
→ 좋은 분할
```

---

# 7. 카이제곱(Chi-Square)

### 개념
- 부모 노드와 자식 노드 사이의 **클래스 분포 차이가 통계적으로 유의한지** 평가
- 관측 빈도와 기대 빈도의 차이를 이용
- **범주형 데이터**를 대상으로 하는 분할에서 활용하기 적합함

```text
카이제곱 값이 클수록
→ 속성과 클래스 사이의 관련성이 클 가능성
→ 분할 기준으로 사용할 가치가 높음
```

# 8. 속성 선택 기준 비교

| 기준 | 핵심 의미 | 주 사용 문제 |
|---|---|---|
| 지니 불순도 | 클래스가 얼마나 섞여 있는지 측정 | 분류 |
| 지니 평가지수 | 분할된 자식 노드 지니 불순도의 가중합 | 분류 |
| 엔트로피 | 데이터의 불확실성/혼잡도 | 분류 |
| 정보이득 | 분할 전후 엔트로피 감소량 | 분류 |
| 분산 감소량 | 분할 전후 분산 감소량 | 회귀 |
| Chi-Square | 클래스 분포 차이의 통계적 유의성 | 범주형 데이터 |

### 시험 핵심

```text
분류
→ Gini, Entropy, Information Gain

회귀
→ Variance Reduction

범주형 속성
→ Chi-Square 활용 가능
```

# 9. 결정트리의 과다적합

## 과다적합(Overfitting)

모델이 학습 데이터의 일반적인 규칙뿐 아니라 **노이즈까지 지나치게 학습하는 현상**이다.

결정트리를 제한 없이 계속 성장시키면:

```text
트리 깊이 증가
→ 학습 데이터에 지나치게 맞춰짐
→ 학습 정확도 증가
→ 새로운 데이터에 대한 성능 저하 가능
```

---

## 과다적합 해결 방법

### 1. 조기 종료(Pre-Pruning)

트리가 너무 크게 성장하기 전에 학습을 중단한다.

예:

- 최대 트리 깊이 제한
- 노드가 가져야 하는 최소 데이터 수 설정
- 리프 노드가 가져야 하는 최소 데이터 수 설정
- 분할에 필요한 최소 성능 향상 기준 설정

```text
트리가 생성되는 과정에서 제한
→ 조기 종료
```

### 2. 가지치기(Post-Pruning)

먼저 충분히 큰 트리를 만든 후 **불필요한 가지를 제거**한다.

```text
큰 트리 생성
→ 중요하지 않은 가지 제거
→ 모델 단순화
```

# 10. 결정트리의 장단점

## 장점
- 결과를 사람이 이해하기 쉬움
- 설명력이 뛰어남
- 데이터의 비선형 관계를 표현할 수 있음
- 특성 스케일링의 필요성이 비교적 낮음
- 분류와 회귀에 모두 사용 가능

## 단점
- 과다적합이 발생하기 쉬움
- 학습 데이터가 조금만 변해도 트리 구조가 크게 달라질 수 있음
- 하나의 결정트리만 사용할 경우 일반화 성능이 떨어질 수 있음

이러한 단점을 보완하기 위해 **여러 결정트리를 결합한 랜덤 포레스트**를 사용할 수 있다.

---

# 11. 랜덤 포레스트(Random Forest)

## 개념

- **결정트리 + 앙상블 학습**을 결합한 방법
- 여러 개의 결정트리를 학습한 뒤 결과를 결합하여 최종 예측을 수행
- 하나의 결정트리에 비해 과다적합을 줄이고 일반화 성능을 높일 수 있음

```text
여러 결정트리
      ↓
각 트리의 예측
      ↓
결과 결합
      ↓
최종 예측
```

---

# 12. 랜덤 포레스트의 학습 과정

## 1. 배깅(Bagging)

원본 학습 데이터에서 **복원 추출(Bootstrap Sampling)** 하여 여러 개의 학습 데이터 집합을 만든다.

```text
원본 데이터
   ↓
Bootstrap Sample 1 → 결정트리 1
Bootstrap Sample 2 → 결정트리 2
Bootstrap Sample 3 → 결정트리 3
...
Bootstrap Sample m → 결정트리 m
```

각 결정트리는 서로 조금씩 다른 데이터를 이용하여 학습한다.

---

## 2. 특성 무작위 선택

랜덤 포레스트는 각 노드를 분할할 때 **전체 특성을 모두 사용하는 것이 아니라 일부 특성을 무작위로 선택한 뒤 그중 좋은 특성을 사용**한다.

이 과정을 통해 각 결정트리들이 서로 비슷하게 만들어지는 것을 줄인다.

```text
배깅
+ 특성의 무작위 선택
= 랜덤 포레스트
```

---

## 3. 여러 결정트리의 결과 결합

### 분류 문제

각 결정트리의 예측 결과에 대해 **다수결 투표(Voting)** 를 수행한다.

예:

```text
Tree 1 → A
Tree 2 → B
Tree 3 → A
Tree 4 → A
Tree 5 → B

최종 결과 → A
```

### 회귀 문제

각 결정트리가 예측한 **출력값의 평균**을 사용한다.

예:

```text
Tree 1 → 10
Tree 2 → 12
Tree 3 → 11

최종 결과
= (10 + 12 + 11) / 3
= 11
```

# 13. 결정트리 vs 랜덤 포레스트

| 구분 | 결정트리 | 랜덤 포레스트 |
|---|---|---|
| 모델 수 | 1개의 트리 | 여러 개의 트리 |
| 학습 방법 | 하나의 전체 데이터로 학습 | Bootstrap으로 여러 데이터 생성 |
| 특성 선택 | 일반적으로 전체 특성에서 선택 | 일부 특성을 무작위 선택 |
| 분류 결과 | 하나의 트리가 결정 | Voting |
| 회귀 결과 | 하나의 트리가 결정 | 각 트리 출력의 평균 |
| 설명력 | 매우 높음 | 결정트리보다 낮음 |
| 과다적합 | 발생하기 쉬움 | 상대적으로 감소 |
| 안정성 | 데이터 변화에 민감 | 상대적으로 안정적 |

# 15. 시험 직전 암기 포인트

### 결정트리
- 결정을 내리는 함수를 **트리 형태**로 표현
- 설명력이 뛰어나지만 **과다적합에 취약**
- 각 노드에서 **어떤 속성으로 데이터를 분할할지 결정하는 것이 핵심**

### 지니 불순도
```text
클래스 혼합 정도 측정
작을수록 좋음
순수한 노드 → 0
```

### 정보이득
```text
분할 전 엔트로피 - 분할 후 엔트로피
클수록 좋음
```

### 분산 감소량
```text
회귀 문제에서 사용
분할 후 분산이 작아지도록 선택
```

### 과다적합 해결
```text
조기 종료
가지치기
```

### 랜덤 포레스트
```text
결정트리 + 앙상블

배깅
+ 특성 무작위 선택
+ 여러 결정트리

분류 → Voting
회귀 → 평균
```
