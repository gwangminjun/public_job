# 힙과 힙 정렬

## 10. 힙(Heap)

힙은 **완전 이진 트리**이면서 힙 조건을 만족하는 자료구조이다.

### 10.1 완전 이진 트리

위에서부터 왼쪽부터 **빈자리 없이 채워지는 이진 트리**이다.

### 10.2 최대 힙 / 최소 힙

#### 최대 힙(Max Heap)

모든 부모 노드가 자식 노드보다 **크거나 같다.**

```text
부모 >= 자식
```

따라서 루트에는 항상 **최댓값**이 위치한다.

#### 최소 힙(Min Heap)

모든 부모 노드가 자식 노드보다 **작거나 같다.**

```text
부모 <= 자식
```

따라서 루트에는 항상 **최솟값**이 위치한다.

### 10.3 힙을 배열로 구현하는 이유

힙은 완전 이진 트리이므로 빈 공간 없이 **1차원 배열**로 효율적으로 저장할 수 있다.

0번 인덱스를 기준으로 할 경우:

```text
부모 인덱스 = i

왼쪽 자식 = 2i + 1
오른쪽 자식 = 2i + 2
부모 = floor((i - 1) / 2)
```

### 10.4 힙의 장점

#### 삽입

새로운 데이터를 배열 마지막에 넣는다.

부모와 비교하면서 힙의 조건을 만족할 때까지 위로 이동한다.

시간복잡도:

**O(log n)**

#### 삭제

최대 힙에서는 최댓값 삭제가 쉽다.

최소 힙에서는 최솟값 삭제가 쉽다.

과정:

1. 루트 데이터 제거
2. 마지막 데이터를 루트로 이동
3. 마지막 위치 삭제
4. 자식 노드와 비교하며 아래로 이동
5. 힙 재구성

시간복잡도:

**O(log n)**

## 11. 힙 정렬(Heap Sort)

힙 자료구조의 특성을 이용한 정렬이다.

오름차순:

> **최대 힙 사용**

내림차순:

> **최소 힙 사용**

### 11.1 힙 정렬 과정

1. 배열을 힙 구조로 변환
2. 루트의 최댓값 또는 최솟값을 정렬될 위치로 이동
3. 남은 데이터로 힙 재구성
4. 반복

### 11.2 초기 힙 구축

#### 방법 1. 순차 삽입 방식

원소를 하나씩 넣으면서 부모와 비교하고 위로 올린다.

전체 힙 구축:

**O(n log n)**

#### 방법 2. 일괄 구축 방식

배열 전체를 완전 이진 트리로 본다.

가장 아래쪽의 부모 노드부터 위쪽으로 `heapify`를 수행한다.

전체 힙 구축:

**O(n)**

### 11.3 힙 정렬 수행시간

- 최선: **O(n log n)**
- 평균: **O(n log n)**
- 최악: **O(n log n)**

이유:

```text
바깥 반복 ≈ n번
heapify ≈ log n

n × log n
= O(n log n)
```

특징:

- **비안정적 정렬**
- **제자리 정렬**
- 입력 데이터의 초기 순서에 따른 성능 변화가 크지 않음
