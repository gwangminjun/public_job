# 시험 직전 핵심 암기

```text
순차 탐색
→ 처음부터 하나씩
→ O(n)

이진 탐색
→ 정렬 필수
→ 가운데 기준 절반 제거
→ O(log n)
```

```text
Greedy
→ 현재 가장 좋아 보이는 선택
→ 국부 최적이 항상 전체 최적을 보장하지는 않음
```

```text
선택 정렬
→ 최솟값 찾아 맨 앞과 교환
```

```text
버블 정렬
→ 인접 데이터 비교·교환
```

```text
삽입 정렬
→ 하나를 뽑아 자기 자리에 삽입
```

```text
셸 정렬
→ 일정 간격을 이용한 삽입 정렬 개선
```

```text
퀵 정렬
→ 피벗 기준 분할
→ 작은 값은 왼쪽
→ 큰 값은 오른쪽
→ 결합 과정 없음
```

```text
합병 정렬
→ 절반씩 분할
→ 정렬하면서 다시 합병
→ 안정적
→ 제자리 X
```

```text
최대 힙
→ 부모 >= 자식
→ 루트 = 최댓값

최소 힙
→ 부모 <= 자식
→ 루트 = 최솟값
```

```text
힙 정렬

오름차순 → 최대 힙
내림차순 → 최소 힙

최선 = O(n log n)
평균 = O(n log n)
최악 = O(n log n)
```

```text
비교 기반 정렬 하한
→ Ω(n log n)
```

```text
분포 기반 정렬
→ 조건이 맞으면 O(n) 가능
```

```text
계수 정렬
→ 출현 횟수 + 누적 횟수
→ O(n+k)
→ 안정적
→ 제자리 X
```

```text
기수 정렬
→ 자릿수별 정렬

LSD → 낮은 자리부터
MSD → 높은 자리부터
```

```text
버킷 정렬
→ 범위를 여러 버킷으로 분할
→ 균등 분포일수록 효율적
```
