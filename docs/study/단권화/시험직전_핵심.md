# 시험 직전 핵심 단권화 (알고리즘 + 머신러닝)

## 알고리즘 — 탐색

| 방법 | 조건 | 시간 | 핵심 |
|---|---|---|---|
| 순차 탐색 | 정렬 불필요 | O(n) | 처음부터 하나씩 |
| 이진 탐색 | **정렬 필수** | O(log n) | 가운데 비교, 절반 제거. 연결 리스트엔 부적합 |
| BST | 왼쪽 < 부모 < 오른쪽 | O(h) | 균형 O(log n), 경사 트리 O(n) |
| 2-3-4 트리 | 모든 리프 레벨 동일 | O(log n) | 4-노드는 가운데 키를 부모로 올려 분할 |

- BST 삭제: 자식 0개 → 제거 / 1개 → 자식을 부모에 연결 / 2개 → **후속자(오른쪽 최솟값)** 또는 선행자로 교체 후 그 노드 삭제.
- 레드-블랙 트리 조건: ① 노드는 빨강/검정 ② **루트는 검정** ③ NIL 리프는 검정 ④ **빨강의 자식은 검정**(빨강 연속 불가) ⑤ 각 노드→리프 경로의 검정 수 동일. 새 노드는 빨강 삽입, 재색칠+회전으로 복구, O(log n).
- B-트리: 키 k개 → 자식 **k+1개**, 모든 리프 레벨 동일, 가득 차면 가운데 키 올려 분할. DB 인덱스 용도.
- 해싱: 평균 O(1). 충돌 해결 = **개방 해싱(체이닝, 연결 리스트)** vs **폐쇄 해싱(개방 주소법: 선형·이차 탐사·이중 해싱)**.
- 선형 탐사 `h(k)+1, +2…` → **1차 군집화** 발생. 이차 탐사 `h(k)+1², +2²…` → 군집화 완화.

## 알고리즘 — 그리디

- 현재 가장 좋아 보이는 선택 반복. **국부 최적이 전체 최적을 보장하지 않음.**
- 반례: 동전 {1,3,4}로 6원 → 그리디 4+1+1(3개), 최적 3+3(2개).
- 분할 가능 배낭: **이익/무게** 큰 순. 대표 알고리즘: Kruskal, Prim, Dijkstra.

## 알고리즘 — 정렬

| 정렬 | 핵심 동작 | 최선/평균/최악 | 안정 | 제자리 |
|---|---|---|---|---|
| 선택 | 최솟값 찾아 맨 앞과 교환 | n²/n²/n² | X | O |
| 버블 | 인접 비교·교환 | n/n²/n² | O | O |
| 삽입 | 정렬된 구간의 제자리에 삽입, 거의 정렬된 데이터에 유리 | n/n²/n² | O | O |
| 셸 | gap 간격 삽입 정렬, gap 수열에 성능 의존 | 수열에 따름 | X | O |
| 퀵 | 피벗 기준 분할, **결합 과정 없음** | nlogn/nlogn/**n²** | X | O |
| 합병 | 절반 분할 후 **합칠 때 정렬**, 추가 배열 O(n) | 모두 nlogn | O | X |
| 힙 | 최대 힙 구축 → 루트와 끝 교환 → 재구성 | 모두 nlogn | X | O |
| 계수 | 출현→누적 횟수로 배치 | O(n+k) | O | X |
| 기수 | 자릿수별 안정 정렬 반복(보통 계수) | O(d(n+b)) | O | X |
| 버킷 | 구간별 분배 후 내부 정렬 | 균등 분포 시 평균 O(n) | 구현에 따름 | X |

- **비교 기반 정렬 하한 = Ω(n log n)** (O=상한, Ω=하한). 분포 기반은 조건 맞으면 O(n) 가능.
- 퀵 최악: 피벗이 계속 최소/최대로 치우칠 때. 기수: **LSD = 낮은 자리부터, MSD = 높은 자리부터.**
- 힙: 완전 이진 트리 + 부모≥자식(최대 힙, 루트=최댓값). 배열(0시작): 왼쪽 2i+1, 오른쪽 2i+2, 부모 floor((i−1)/2).
- 힙 구축: 하나씩 삽입 O(n log n), **일괄(bottom-up heapify) O(n)**. 오름차순=최대 힙, 내림차순=최소 힙.

## 알고리즘 — 그래프

- G=(V,E). **트리 = 연결된 무방향 그래프 + 사이클 없음**, 간선 수 n−1.
- 인접 행렬: 공간 O(V²), 간선 확인 O(1). 인접 리스트: 공간 O(V+E), 희소 그래프에 유리.
- **DFS = 스택(재귀), 깊게** / **BFS = 큐, 가까운 정점부터 층별.** 인접 리스트 기준 둘 다 O(V+E).
- **위상 정렬: DAG(방향+무사이클)에서만** 가능. DFS 종료 순서의 **역순**. 답이 여러 개일 수 있음.
- 연결 성분 = **무방향** 최대 연결 부분 그래프 / 강연결 성분(SCC) = **방향** 그래프에서 서로 왕복 가능.

## 머신러닝 — 기본과 베이즈·K-NN

- **AI ⊃ 머신러닝 ⊃ 딥러닝.** 지도학습(정답 O → 분류·회귀) / 비지도학습(정답 X → 군집화·차원축소) / 강화학습(보상).
- 베이즈: **사후확률 = 우도 × 사전확률 / 증거**, 사후확률이 가장 큰 클래스 선택.
- 공분산별 분류: 공통 단위행렬 → **최소거리(유클리드)** / 공통 공분산 → **마할라노비스**(분산·상관 고려, 선형 경계) / 클래스별 다름 → 이차 경계.
- K-NN: 가까운 K개의 **다수결**. K 작으면 잡음 민감, 크면 경계 평활. 학습은 데이터 저장뿐(거리 기반).

## 머신러닝 — 특징 추출·회귀

| 방법 | 레이블 | 변환 | 핵심 |
|---|---|---|---|
| PCA | X (비지도) | 선형 | **분산 최대 방향**, 공분산 행렬 고유벡터. 중심화→공분산→고유치→선택→사영 |
| LDA | O (지도) | 선형 | 클래스 간 산점도 크게 / 내 산점도 작게. 판별 축 최대 **C−1개** |
| MDS | X | — | 거리 관계 보존 |
| t-SNE | X | 비선형 | 입력 가우시안·출력 t-분포 유사도, 시각화용 |
| Isomap | X | 비선형 | 근접 그래프 최단경로 = **측지 거리** |

- 잔차 = y−ŷ. 최소제곱법 = 잔차 **제곱합** 최소화. MSE = 평균제곱오차, RMSE = √MSE(**출력과 같은 단위**).
- 로지스틱 회귀 = **분류 모델**. 선형함수 → 시그모이드 → 0~1 확률. **오즈 = p/(1−p), 로짓 = log(p/(1−p)) = wᵀx+b.**
- 학습: 선형회귀 = 최소제곱법 / 로지스틱 = **최대우도추정(MLE)** = 교차 엔트로피 최소화.

## 머신러닝 — SVM·결정트리·앙상블

- SVM = **최대 마진 분류기**. 마진 = 결정경계~가장 가까운 데이터 거리. **서포트 벡터** = 그 가장 가까운 데이터. 기본은 이진 분류.
- 하드 마진 = 완벽 분리 / 소프트 마진 = **슬랙 변수**로 위반 허용. C 크면 위반 벌점 큼.
- **커널 트릭**: 고차원 매핑 Φ를 직접 계산하지 않고 K(x,z)로 내적 효과. 슬랙(오류 허용)과 커널(비선형)은 역할이 다름.
- 결정트리 기준: 지니 `1−Σp²`·엔트로피 → 작게 / **정보이득**(부모−자식 가중 엔트로피)·**분산 감소량(회귀)** → 크게 / 카이제곱 = 범주형.
- 과적합 대책: 조기 종료(Pre-Pruning), 가지치기(Post-Pruning).
- **랜덤 포레스트 = 배깅(부트스트랩) + 분할마다 특성 무작위 선택.** 분류=투표, 회귀=평균.
- **배깅** = 복원추출·병렬·**분산 감소** / **부스팅** = 순차, 앞의 오류 보완. **AdaBoost** = 틀린 데이터 가중치 증가 + 가중 보팅.
- 데이터 생성: 리샘플링→배깅 / 가중치 조정→AdaBoost / 필터링→초기 부스팅·캐스케이딩.
- 스태킹 = 메타 학습기가 **결합 방법을 학습** / 캐스케이딩 = 쉬운 것부터, 어려운 데이터만 다음 단계로 / 전문가 혼합 = 출력 가중합.

## 머신러닝 — 군집화

- K-평균: K개 중심 → **할당(가까운 중심) → 갱신(군집 평균)** 반복. 목적 = 거리 제곱합 최소화. **초기값·K에 민감**, 지역 최적 가능(→ K-Means++, 엘보우·실루엣).
- 계층적: 병합적 = Bottom-Up / 분할적 = Top-Down. 결과는 덴드로그램.
- 연결법: 최단(가장 가까운 쌍, 체이닝 현상)·최장(가장 먼 쌍)·중심·평균·**Ward(제곱오차 증가 최소)**.
- K-평균의 K = 군집 수, K-NN의 K = 이웃 수. 혼동 금지.

## 머신러닝 — 신경망·MLP

- 인공신경망 3요소: **뉴런 + 연결 구조 + 학습 알고리즘.** 뉴런 = 가중합(u=Σwx+b) + 활성화 함수.
- 활성화: 계단 0/1, **부호 −1/1(계단과 구분)**, 시그모이드 0~1(기울기 소실), tanh −1~1, **ReLU = max(0,u)**.
- 퍼셉트론 = 단층·전방향·완전연결·지도학습·**선형 경계만** → **XOR 해결 불가.** MLP = 은닉층 + 비선형 활성화로 해결.
- 역전파 = 기울기 강하법을 MLP에 적용: **순전파 → 오차 계산 → 역전파(출력→은닉, 연쇄법칙) → 가중치 수정.** 은닉층은 목표값이 없어 출력층 오차를 역전파해 사용.
- 학습률: 너무 크면 발산, 작으면 느림. 모멘텀 = 이전 이동 방향 반영. Early Stopping = 검증 오차 상승 시 종료.
- 학습 모드: **온라인 = 1개마다 / 배치 = 전체 후 1회 / 미니배치 = 묶음마다(표준).** Epoch = 전체 데이터 1회 사용.
- 출력층·손실: **회귀 = 선형+MSE / 이진 = 시그모이드+BCE / 다중 = 소프트맥스+교차 엔트로피.**
- MNIST: 28×28 흑백 = **784차원**, 학습 60,000 / 테스트 10,000, 출력 10클래스, 목표는 원핫 벡터.

## 머신러닝 — CNN·RNN

- CNN = **국소 연결 + 가중치 공유.** 구성: 콘볼루션층 + 풀링층 + 완전연결층.
- 패딩 = 가장자리 채워 크기 유지(Zero Padding) / 스트라이드 = 필터 이동 간격 / 출력 크기 = floor((N+2P−F)/S)+1.
- **풀링: 학습 파라미터 없음, 채널 수 유지, 가로·세로만 감소** (28×28×32 → 14×14×32). Max/Average.
- 지역 극소 → **시뮬레이티드 어닐링, SGD** / 느린 학습(플라토·안장점·기울기 소멸) → ReLU, Xavier·He 초기화, 모멘텀, **RMSProp·Adam**, 배치 정규화 / 과적합 → **조기 종료, 정규항(L1·L2), 드롭아웃, 데이터 증대.**
- 순차 데이터 = 순서 중요·길이 가변·문맥 의존. RNN = 이전 은닉 상태를 현재 계산에 사용, **시간축 가중치 공유**, 학습은 **BPTT**.
- 구조: 1:m(영상설명) / m:1(감정 분류) / m:n(번역). 문제: 기울기 소멸·폭발, **장기 의존성**.
- **LSTM = 셀 상태 + 게이트 3개(망각·입력·출력) / GRU = 게이트 2개(리셋·갱신).** 장기 의존성 완화.

## 머신러닝 — 영상·NLP

| 모델 | 구분점 |
|---|---|
| AlexNet | 2012 ILSVRC 우승, **5 Conv + 3 FC** |
| VGG | 11·13·16·19층, 전이학습에 활용 |
| GoogLeNet | **Inception 모듈**, 22층 |
| ResNet | **Residual 모듈 + Skip Connection**, 152층 |
| R-CNN / Faster R-CNN | 객체검출. 후보영역 약 2,000개 / 영역 제안망 포함 |
| YOLO | **탐지+인식 한 번에**, 실시간 |
| Show and Tell | 영상설명 = GoogLeNet + LSTM (+Attention이면 Show, Attend and Tell) |

- 오토인코더 = Encoder → **z(축약 특징이 목적)** → Decoder, 입력 복원 학습.
- U-Net = **의료영상 분할**, U자형(Contracting + Expanding + Skip). GAN = 생성기(속인다, 1 판정 유도) vs 판별기(구분한다, 0 판정) **상반된 목적.**
- O/X 단골: Inception=GoogLeNet, Residual=ResNet(바꾸면 X). U-Net은 인식이 아니라 분할.
- 전처리: **토큰화 = 나누기 / 정제 = 노이즈 제거 / 정규화 = 표현 통일**(정제·정규화 혼동 주의).
- 표현: 원핫 = 고차원 희소·**유사성 표현 불가** / BoW = 빈도(순서 무시) / DTM = 문서×단어 행렬 / **TF-IDF = 문서 내 빈도 + 전체 문서 희소성** / 임베딩 = 저차원 밀집 실수 벡터.
- Word2Vec: **CBOW = 주변→중심 / Skip-gram = 중심→주변.**
- Seq2Seq = Encoder+Decoder, **고정 문맥 벡터가 병목** → Attention = 출력마다 인코더 전체에서 중요한 부분 선택 → **Transformer = RNN 제거 + Self-Attention + 병렬 처리.**
- **BERT = Transformer Encoder** 기반, 사전학습→미세조정, 임베딩 = **Token + Segment + Position.**
- LLM: 사전학습→미세조정→추론→평가. **Few-shot CoT = 추론 예시 제공 / Zero-shot CoT = 예시 없이 단계적 추론 지시.**

## 머신러닝 — 강화학습

- **MDP 5요소: 상태, 행동, 상태전이확률, 보상, 할인율.** 마르코프 성질 = **현재 상태만**으로 다음이 결정.
- 정책 = 행동 선택 규칙. 수익 = 할인된 미래 보상의 합. **V(s) = 상태의 기대 수익 / Q(s,a) = 상태+행동의 기대 수익.**
- Q-학습: `Q(s,a) ← Q(s,a) + α[r + γ·maxQ(s′,a′) − Q(s,a)]`. 행동→보상·새 상태→Q 갱신 반복.
- **탐험 = 랜덤 행동 / 탐사(활용) = 현재 Q 기준 최선 / ε-greedy = 혼합**, 갈수록 탐사 비중 증가.
- Q-테이블: 상태 많으면 비효율 → Q-신경망(입력=상태, 출력=행동별 Q값, 불안정) → **DQN = CNN 기반(초기 2 Conv+2 FC) + 경험 재현 + 목표망.**
