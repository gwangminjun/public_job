# 알고리즘 단권화

원문 9개를 7개 주제로 통합했다. `전공 - 알고리즘.md`와 개별 문서의 중복 본문은 한 번만 정리했다. 각 주제의 자세한 예제는 화면의 **원문 참고**에서 확인한다.

## 탐색과 이진 탐색 트리

**암기 흐름: 순차 → 정렬된 배열의 이진 탐색 → BST → 균형 유지.**

| 방법 | 전제와 동작 | 탐색 시간 |
|---|---|---|
| 순차 탐색 | 정렬 불필요, 처음부터 하나씩 비교 | O(n) |
| 이진 탐색 | 정렬된 배열, 가운데와 비교해 범위를 절반으로 축소 | O(log n) |
| BST | 왼쪽 서브트리 < 현재 키 < 오른쪽 서브트리 | O(h), 균형 시 O(log n), 편향 시 O(n) |
| 2-3-4 트리 | 모든 리프의 깊이가 같고 노드에 여러 키 저장 | O(log n) |

- **BST 삭제**: 자식 0개 → 제거 / 1개 → 자식을 부모에 연결 / 2개 → 오른쪽 최솟값(후속자) 또는 왼쪽 최댓값(선행자)으로 대체 후 그 노드 삭제.
- **2·3·4-노드**: 각각 키 1·2·3개, 최대 자식 2·3·4개. 4-노드 분할 시 가운데 키를 부모로 올리고 양쪽으로 나눈다.
- 이진 탐색은 중간 원소에 바로 접근할 수 있는 배열에 적합하다. 연결 리스트에서는 중간까지 이동해야 하므로 같은 효율을 기대할 수 없다.

> 주의: 일반 BST가 항상 O(log n)은 아니다. 1, 2, 3, 4 순으로 삽입하면 편향될 수 있다. 배열 중간 삽입·삭제에는 원소 이동 비용도 든다.

## 균형 탐색 트리와 해싱

| 구조 | 기억할 조건 | 용도·성능 |
|---|---|---|
| 레드-블랙 트리 | 루트·NIL은 검정, 빨강의 자식은 검정, 각 노드에서 NIL까지 검정 수 동일 | 회전·재색칠로 균형, 탐색·삽입·삭제 O(log n) |
| B-트리 | 한 노드에 여러 키·자식, 모든 리프 깊이 동일 | 디스크 접근 횟수를 줄이는 다방향 균형 트리 |
| 해시 테이블 | 키를 해시 함수로 주소에 대응 | 적절한 분산·적재율에서 평균 O(1), 최악 O(n) |

- **해시 함수**: 제산법 `h(k) = k mod m`, 중간제곱법, 접지법(분할한 키 조각 결합), 숫자분석법.
- **충돌**: 서로 다른 키가 같은 주소로 매핑되는 현상. 적재율은 `저장된 항목 수 / 테이블 크기`.
- **개방 해싱(체이닝)**: 같은 주소의 항목을 연결 리스트 등 별도 구조로 연결한다.
- **폐쇄 해싱(개방 주소법)**: 테이블 안의 다른 빈 슬롯을 찾는다.
- 선형 탐사: `(h(k) + i) mod m`, 연속 빈칸을 찾아 **1차 군집화** 발생.
- 이차 탐사: `(h(k) + c₁i + c₂i²) mod m`, 1차 군집화를 완화하지만 같은 시작 주소는 같은 탐사 경로를 따를 수 있다.

> 주의: **개방 해싱**과 **개방 주소법**을 혼동하지 말 것. 해싱의 O(1)은 최악 보장이 아니다. B-트리의 차수 정의는 교재의 규약을 확인한다.

## 욕심쟁이 방법

**현재 단계에서 가장 좋아 보이는 선택을 반복한다.** 국부 최적 선택이 전체 최적해를 보장하는 문제에 적용한다.

| 문제·알고리즘 | 선택 기준·조건 |
|---|---|
| 거스름돈 | 큰 동전부터 선택, 임의의 동전 체계에서 최적 보장 불가 |
| 분할 가능 배낭 | 이익/무게가 큰 물체부터, 남은 용량만큼 쪼개 담기 |
| Kruskal | 작은 간선부터 선택하되 사이클 방지, 최소 신장 트리 |
| Prim | 현재 트리와 외부 정점을 잇는 최소 간선, 최소 신장 트리 |
| Dijkstra | 현재 최단거리 후보가 가장 작은 정점 확정, 음수 간선 없는 경우 |

**반례**: 동전 `{1, 3, 4}`, 금액 6 → 그리디는 `4+1+1`(3개), 최적은 `3+3`(2개).

> 주의: 분할 가능 배낭의 이익/무게 전략을 0/1 배낭에 그대로 적용하면 최적해를 보장하지 못한다.

## 비교 기반 정렬

- **내부/외부 정렬**: 메모리 안에서 처리 / 메모리에 다 담기지 않아 보조기억장치 활용.
- **안정성**: 같은 키의 기존 상대 순서를 유지. **제자리**: 큰 보조 배열 없이 기존 공간을 주로 활용.

| 정렬 | 핵심 동작 | 최선 / 평균 / 최악 | 안정성(일반 구현) |
|---|---|---|---|
| 선택 | 최솟값을 미정렬 부분의 맨 앞과 교환 | n² / n² / n² | X |
| 버블 | 인접 원소 비교·교환 | n / n² / n² | O |
| 삽입 | 현재 원소를 앞의 정렬된 구간에 삽입 | n / n² / n² | O |
| 셸 | 간격을 둔 삽입 정렬, 간격을 줄여 반복 | 간격 수열에 의존 | X |
| 퀵 | 피벗 기준 작은 값·큰 값으로 분할 | n log n / n log n / n² | X |
| 합병 | 반으로 분할한 뒤 정렬된 부분을 병합 | n log n / n log n / n log n | O |

위 표의 시간은 Big-O 기준이다. 버블 최선 O(n)은 **교환이 없으면 조기 종료하는 구현**에서 성립한다.

- 퀵 정렬: **분할할 때 일함**, 별도 병합 과정 없음. 분할이 계속 극단적으로 치우치면 O(n²).
- 합병 정렬: **합칠 때 정렬함**, 배열 구현에서 보조 공간 O(n). 같은 키는 왼쪽 원소를 먼저 선택해야 안정성 유지.
- 선택·버블·삽입·셸은 통상 제자리 정렬. 퀵은 배열 내 분할이 가능하지만 **재귀 스택 비용**은 별도다.

> 주의: 셸 정렬의 복잡도를 간격 수열과 무관하게 하나로 외우지 않는다. 거의 정렬된 작은 입력에서는 삽입 정렬이 유리하다.

## 힙과 힙 정렬

**힙 = 완전 이진 트리 + 부모·자식 간 순서 조건.** 마지막 층을 제외하고 채워져 있으며 마지막 층은 왼쪽부터 채운다.

| 구분 | 조건 | 루트 |
|---|---|---|
| 최대 힙 | 부모 ≥ 자식 | 최댓값 |
| 최소 힙 | 부모 ≤ 자식 | 최솟값 |

- 배열 표현(0부터 시작): 부모 `floor((i−1)/2)`, 왼쪽 `2i+1`, 오른쪽 `2i+2`.
- **오름차순 힙 정렬**: 최대 힙 구축 → 루트와 마지막 원소 교환 → 힙 크기 1 감소 → 루트에서 내려가며 힙 복구 → 반복.
- **내림차순**: 최소 힙을 이용해 같은 방식으로 뒤부터 확정.
- 아래에서 위로 초기 힙 구축 **O(n)**, 한 번의 삽입·삭제/힙 복구 **O(log n)**, 전체 정렬 **O(n log n)**.
- 힙 정렬은 통상 **제자리·비안정적**이며 최선·평균·최악 모두 O(n log n)으로 정리한다.

> 주의: 힙은 BST가 아니다. 형제끼리나 왼쪽·오른쪽 서브트리 전체의 대소 관계를 보장하지 않는다. 하나씩 삽입해 구축하면 O(n log n)이 들 수 있다.

## 분포 기반 정렬

**비교 기반 정렬의 최악 시간 하한은 Ω(n log n).** 키의 범위·자릿수·분포 정보를 이용하는 정렬은 비교 모델의 하한에 그대로 묶이지 않는다.

| 정렬 | 방법 | 시간·조건 |
|---|---|---|
| 계수 | 값별 개수 → 누적 개수 → 결과 배열에 배치 | O(n+k), k는 키 범위 크기 |
| 기수 | 자릿수마다 정렬 반복 | O(d(n+b)), d는 자릿수·b는 진법/버킷 수 |
| 버킷 | 값 범위를 버킷으로 나누고 각각 정렬 후 연결 | 균등 분포 등 조건에서 기대 O(n), 편중 시 악화 |

- 계수 정렬: 작은 정수 범위에 적합. 보조 배열을 쓰며, 표준 안정 구현은 입력의 상대 순서를 보존하도록 배치한다.
- **LSD**: 낮은 자리 → 높은 자리. 각 자릿수 정렬의 안정성이 필요하다.
- **MSD**: 높은 자리 → 낮은 자리. 같은 접두 값을 가진 그룹을 재귀적으로 정렬한다.
- 버킷 정렬: 일부 버킷에 몰리고 버킷 안에서 삽입 정렬을 쓰면 최악 O(n²)까지 가능하다.

> 주의: 분포 정렬이 무조건 O(n)은 아니다. 계수의 k, 기수의 d·b, 버킷의 분포 조건을 함께 적는다.

## 그래프와 순회

**G = (V, E)**: 정점 집합 V, 간선 집합 E. 트리는 **연결된 무방향 그래프이면서 사이클이 없는 그래프**다.

| 구분 | 핵심 |
|---|---|
| 방향 / 무방향 | 간선에 방향 존재 / 없음 |
| 가중 그래프 | 간선에 비용·거리 등 가중치 존재 |
| 인접 행렬 | 공간 O(V²), 간선 유무 확인 O(1) |
| 인접 리스트 | 공간 O(V+E), 희소 그래프에 적합 |
| DFS | 스택 또는 재귀, 한 방향으로 깊게 가고 되돌아오기 |
| BFS | 큐, 가까운 정점부터 층별 방문 |

- 인접 리스트의 DFS·BFS는 **O(V+E)**, 인접 행렬은 통상 **O(V²)**. 방문 표시로 반복 방문을 막는다.
- BFS는 **무가중 그래프**에서 시작점 기준 간선 수가 최소인 경로를 구할 수 있다.
- **위상 정렬**: DAG(방향 비순환 그래프)에서 선행 조건을 만족하는 정점 순서. DFS 종료 순서의 역순으로 구할 수 있으며 답이 여러 개일 수 있다.
- **연결 성분**: 무방향 그래프에서 서로 연결된 최대 부분 그래프.
- **강연결 성분(SCC)**: 방향 그래프에서 임의의 두 정점이 서로에게 도달할 수 있는 최대 부분 그래프.

> 주의: 사이클이 있는 방향 그래프에는 위상 정렬이 없다. BFS의 최단경로 성질을 임의의 가중 그래프에 적용하지 않는다.
