# 머신러닝 단권화

원문 11개의 개념·비교·암기 항목을 15개 주제로 통합했다. 기본 정의는 처음 등장하는 주제에서 설명하고, 응용 주제에서는 차이를 중심으로 정리했다. 세부 유도·그림·강의 예제는 **원문 참고**에서 확인한다.

## 학습의 기본 개념

**인공지능 ⊃ 머신러닝 ⊃ 딥러닝**. 머신러닝은 데이터에서 규칙을 학습하고, 딥러닝은 심층 신경망을 이용한다. 약 AI는 특정 과제 수행, 강 AI는 일반적인 이해·사고 능력을 지향한다.

| 구분 | 학습 신호 | 대표 문제 |
|---|---|---|
| 지도학습 | 입력과 정답 레이블 | 분류, 회귀 |
| 비지도학습 | 정답 없이 데이터 구조 탐색 | 군집화, 차원 축소 |
| 강화학습 | 환경과 상호작용하며 받은 보상 | 누적 보상을 높이는 정책 학습 |

- **분류**: 어느 클래스인가? **회귀**: 연속값이 얼마인가? **군집화**: 어떤 데이터끼리 비슷한가?
- 학습: `데이터 → 전처리 → 특징 표현 → 목적함수 최적화 → 모델`.
- 추론: `새 데이터 → 학습 때와 같은 전처리·특징 표현 → 모델 → 예측`.
- 특징 벡터는 한 데이터를 수치 벡터로 표현한 것. Flatten은 다차원 배열을 1차원으로 펼치는 것으로, 28×28 영상은 784차원이다.
- 손실함수는 예측 오차를 수치화한다. 학습 데이터로 파라미터를 학습하고, 검증 데이터로 설정을 선택하며, 테스트 데이터로 최종 일반화 성능을 평가한다.

> 주의: 전처리 통계도 학습 데이터에서 구해야 한다. 테스트 데이터를 모델 선택에 반복 사용하면 평가에 정보가 새어 들어간다.

## 베이즈와 K-NN

**베이즈 분류: 사후확률 P(C|x)가 가장 큰 클래스를 선택한다.**

`P(C|x) = P(x|C)P(C) / P(x)` → 사후확률 = 우도 × 사전확률 / 증거.

| 방법 | 기억할 기준 |
|---|---|
| 가우시안 베이즈 | 클래스별 데이터를 가우시안 분포로 모델링 |
| 공통 구형 공분산 | 동일 사전확률이면 유클리드 최소거리 판별과 연결 |
| 공통 일반 공분산 | 선형 결정경계, 마할라노비스 거리와 연결 |
| 클래스별 다른 공분산 | 일반적으로 이차 결정경계 |
| 1-NN | 가장 가까운 학습 데이터 1개의 클래스 |
| K-NN 분류 | 가까운 K개 이웃의 다수결(또는 거리 가중 투표) |

- K-NN은 예측 시 학습 데이터를 참조한다. 거리 척도와 특성 스케일의 영향을 받는다.
- K가 너무 작으면 잡음에 민감하고, 너무 크면 국소 경계가 과도하게 평활해질 수 있다.
- 다중 클래스 베이즈 분류는 각 클래스 사후확률을 계산해 최댓값을 고른다.

> 주의: 공분산 조건만 보고 항상 최소거리라고 단정하지 않는다. 사전확률이 다르면 결정 기준에도 반영된다.

## 특징 추출과 차원 축소

**특징 추출**은 원래 데이터 x를 유용한 표현 y로 변환하는 것. 차원 축소는 n차원을 m차원(m<n)으로 줄이는 경우다. 수작업 특징과 표현학습, 선형·비선형 변환을 구분한다.

| 방법 | 레이블·목표 | 핵심 원리 |
|---|---|---|
| PCA | 레이블 불필요, 분산 보존 | 큰 고유값에 대응하는 직교 방향으로 사영 |
| LDA | 레이블 사용, 클래스 분리 | 클래스 간 산점도 크게 / 클래스 내 산점도 작게 |
| MDS | 데이터 간 거리 보존 | 저차원 거리로 원래 거리를 근사 |
| t-SNE | 이웃 유사도 보존·시각화 | 입력의 가우시안 유사도, 출력의 t-분포 |
| Isomap | 비선형 매니폴드 구조 | 근접 그래프 → 최단경로로 측지 거리 근사 → 저차원 표현 |

- **PCA 순서**: 중심화 → 공분산 행렬 → 고유값·고유벡터 → 큰 고유값 순으로 선택 → 사영.
- 누적 설명 분산 비율로 축소 차원 수를 선택할 수 있다. 스케일 차이가 크면 표준화 여부도 검토한다.
- **LDA 기준**: `J(w) = (wᵀ S_B w) / (wᵀ S_W w)`. 판별 축은 최대 `min(특성 수, 클래스 수−1)`개다.
- 선형 변환만으로 복잡한 비선형 구조를 충분히 반영하지 못할 수 있다.

> 주의: PCA의 큰 분산 방향이 반드시 클래스 분리에 최적인 방향은 아니다. t-SNE 그림의 군집 간 거리·크기를 원래 데이터의 전역 구조로 단정하지 않는다.

## 선형회귀와 로지스틱 회귀

| 구분 | 선형회귀 | 로지스틱 회귀 |
|---|---|---|
| 목적 | 연속값 예측 | 클래스 확률 예측·분류 |
| 출력 | 선형 결합 `ŷ = wᵀx+b` | `p = 1/(1+exp(−z))` |
| 학습 | 잔차 제곱합 최소화 | 베르누이 우도 최대화, 교차 엔트로피 최소화 |

- 잔차: `y−ŷ`. 최소제곱법: 잔차 제곱합을 최소화한다.
- **MSE**: `Σ(y−ŷ)²/n`. **RMSE**: `√MSE`, 출력값과 같은 단위를 갖는다.
- 여러 입력변수로 하나의 값을 예측하는 형태는 **다중 선형회귀**다(원문의 “다변량” 항목).
- **오즈**: `p/(1−p)`. **로짓**: `log(p/(1−p)) = wᵀx+b`.
- 로지스틱 회귀는 예측 확률에 임계값을 적용해 클래스를 정한다. 임계값 0.5는 흔한 선택이며 고정된 필수 조건은 아니다.

> 주의: 이름에 “회귀”가 있어도 로지스틱 회귀는 여기서 **분류 모델**이다. MSE와 RMSE의 단위 및 큰 오차에 대한 민감도를 구분한다.

## SVM과 커널

**SVM은 분류 경계와 가까운 데이터 사이의 마진을 크게 만드는 분류기다.** 서포트 벡터는 결정경계에 영향을 주는 핵심 학습 표본이다.

- 선형 결정경계: `wᵀx+b = 0`, 표준 정규화에서 두 마진 경계 사이 폭은 `2/‖w‖`.
- **하드 마진**: 선형 분리 가능, 마진 위반 허용 안 함.
- **소프트 마진**: 슬랙 변수 ξ로 마진 위반을 허용. `½‖w‖² + CΣξ`를 최소화한다.
- **C가 큼**: 위반에 큰 벌점. **C가 작음**: 더 강한 정규화, 위반을 상대적으로 허용.
- 기본 SVM은 이진 분류기. 다중 클래스는 일대다·일대일 등으로 확장한다.

| 커널 | 핵심 |
|---|---|
| 선형 | `K(x,z)=xᵀz` |
| 다항식 | 다항 특징의 내적을 암묵적으로 계산 |
| RBF | 거리 제곱에 기반한 유사도, 비선형 경계 |

**커널 트릭**: 고차원 특징을 직접 전부 만들지 않고, 그 공간의 내적 `K(x,z)=φ(x)ᵀφ(z)`을 계산한다.

> 주의: 슬랙 변수는 마진 위반을 허용하고, 커널은 비선형 표현을 다룬다. 서로 같은 역할이 아니다. 마진 안에 들어온 표본이 모두 오분류인 것도 아니다.

## 결정트리와 랜덤 포레스트

**결정트리**는 질문으로 데이터를 나누어 리프에서 예측하는 모델이다. 핵심은 **어떤 속성·기준으로 분할할지** 선택하는 것이다.

| 기준 | 정의·선호 방향 |
|---|---|
| 지니 불순도 | `1−Σpₖ²`, 순수하면 0, 작게 |
| 엔트로피 | `−Σpₖ log₂pₖ`, 순수하면 0 |
| 정보이득 | 부모 엔트로피 − 자식들의 **표본 수 가중** 엔트로피, 크게 |
| 분산 감소량 | 회귀에서 분할 후 가중 분산을 줄이는 정도, 크게 |
| 카이제곱 | 속성과 클래스의 독립성에서 벗어나는 정도를 평가 |

- 장점: 규칙으로 설명하기 쉬움, 비선형 관계 처리. 단점: 과적합과 데이터 변화에 따른 구조 불안정.
- 과적합 대책: 최대 깊이·최소 표본 수 등으로 **조기 종료**, 불필요한 가지 **가지치기**.
- **랜덤 포레스트 = 부트스트랩 표본 + 분할마다 무작위 특성 후보 + 여러 결정트리**.
- 분류는 투표, 회귀는 평균으로 결합해 개별 트리의 분산을 줄인다.

> 주의: 분할 후 불순도를 비교할 때 자식 노드 크기가 다르면 단순 평균이 아니라 표본 수로 가중한다. 랜덤 포레스트는 데이터를 뽑는 무작위성과 특성을 뽑는 무작위성을 함께 쓴다.

## 앙상블 학습

여러 학습기의 예측을 결합한다. 알고리즘·파라미터·학습 데이터를 다르게 하여 **다양성**을 만든다.

| 방법 | 학습·결합 원리 |
|---|---|
| 배깅 | 복원추출(부트스트랩) 데이터로 병렬 학습 → 평균·투표 |
| 부스팅 | 앞 학습기의 부족한 부분을 다음 학습기가 순차 보완 |
| AdaBoost | 잘못 분류한 표본의 가중치를 높이고 학습기들을 가중 투표 |
| 스태킹 | 기본 모델의 예측을 입력으로 메타 모델이 결합 방법 학습 |
| 캐스케이딩 | 쉬운 판단부터 적용, 어려운 데이터를 다음 단계로 전달 |
| 전문가 혼합 | 입력에 따라 전문가의 기여도를 정해 출력을 가중 결합 |

- **복원추출**: 같은 표본이 여러 번 뽑힐 수 있다.
- 평균법은 주로 수치 출력·회귀, 보팅은 주로 클래스·분류. 가중 평균·가중 투표도 가능하다.
- 배깅은 불안정한 모델의 분산 감소에 유용하다. 부스팅은 잔여 오류를 줄이지만 잡음·이상치에 민감할 수 있다.
- 원문 데이터 생성 구분: 리샘플링 → 배깅, 가중치 조정 → AdaBoost, 필터링 → 초기 부스팅·캐스케이딩.

> 주의: 앙상블은 모델 개수만 늘린다고 무조건 좋아지지 않는다. 모델들이 같은 오류를 내면 결합의 이점이 줄어든다.

## 군집화

**레이블 없이 비슷한 데이터끼리 묶는 비지도학습**이다.

- **K-평균**: K개 중심 초기화 → 가장 가까운 중심에 할당 → 각 군집 평균으로 중심 갱신 → 변화가 충분히 작아질 때까지 반복.
- 목적: `Σₖ Σ(x∈Cₖ) ‖x−μₖ‖²` 최소화. 초기값과 K 선택에 민감하며 전역 최적을 항상 보장하지 않는다.
- K를 늘리면 군집 내 오차가 감소하기 쉬우므로 오차가 작다는 이유만으로 K를 크게 정하지 않는다.
- **계층적 군집화**: 병합적 = 작은 군집부터 합침(Bottom-Up), 분할적 = 큰 군집을 나눔(Top-Down).

| 연결법 | 군집을 비교하는 기준 |
|---|---|
| 최단(Single) | 가장 가까운 표본 쌍 |
| 최장(Complete) | 가장 먼 표본 쌍 |
| 중심(Centroid) | 중심점 사이 거리 |
| 평균(Average) | 두 군집 표본 쌍 거리의 평균 |
| Ward | 병합으로 증가하는 군집 내 제곱오차가 가장 작게 |

> 주의: K-평균의 K는 군집 수, K-NN의 K는 예측에 사용할 이웃 수다. 군집 번호는 미리 주어진 정답 클래스가 아니다.

## 신경망과 퍼셉트론

**인공신경망의 3요소: 뉴런 + 연결 구조 + 학습 알고리즘.** 뉴런은 `z = Σwᵢxᵢ+b`, 출력은 `a=f(z)`로 계산한다.

| 활성화 함수 | 특징·주의 |
|---|---|
| 계단 / 부호 | 임계값에 따라 0·1 / −1·1, 미분 기반 학습에 제약 |
| 선형 | 입력의 선형 변환, 여러 층을 쌓아도 전체는 선형 |
| 시그모이드 | 출력 (0,1), 큰 절댓값 입력에서 포화·기울기 소멸 |
| tanh | 출력 (−1,1), 영 중심이지만 포화 가능 |
| ReLU | `max(0,z)`, 양수 영역 기울기 1, 죽은 뉴런 가능 |

- M-P 뉴런은 임계값 논리 모델. 퍼셉트론은 가중치를 학습하지만 단층에서는 선형 분리 가능한 문제만 해결한다.
- **XOR**는 하나의 직선으로 두 클래스를 분리할 수 없어 단층 퍼셉트론으로 해결 불가.
- **MLP**: 입력층 → 하나 이상의 은닉층 → 출력층. 비선형 활성화 함수를 이용해 비선형 결정경계를 학습한다.
- 전방향 신경망은 입력에서 출력으로 흐르고, 순환 신경망은 이전 상태 정보를 현재 계산에 활용한다.

> 주의: 은닉층을 늘려도 활성화가 모두 선형이면 비선형 표현력이 생기지 않는다. 역전파는 학습 시 기울기를 전달하는 절차이며 순환 연결 자체를 뜻하지 않는다.

## MLP 학습과 MNIST

**전방향 계산 → 손실 계산 → 역전파로 기울기 계산 → 최적화 알고리즘으로 가중치 갱신.**

- 경사하강법: `w ← w−η∂L/∂w`. η는 학습률. 너무 크면 진동·발산, 너무 작으면 느린 수렴.
- 역전파는 **연쇄법칙**으로 출력층에서 입력층 방향으로 기울기를 계산한다. 가중치 갱신 방법과 구분한다.
- 모멘텀은 이전 갱신 방향을 활용한다. 검증 손실을 보며 조기 종료하고, 테스트셋은 최종 평가에 사용한다.

| 학습 모드 | 한 번 갱신에 사용하는 표본 |
|---|---|
| 온라인 | 1개 |
| 배치 | 전체 학습 데이터 |
| 미니배치 | 일부 묶음 |

| 문제 | 대표 출력층 | 대표 손실 |
|---|---|---|
| 회귀 | 선형 | MSE |
| 이진 분류 | 시그모이드 | 이진 교차 엔트로피 |
| 단일 정답 다중 클래스 | 소프트맥스 | 범주형 교차 엔트로피 |

- **Epoch**: 전체 학습 데이터를 한 번 처리. 에포크 수와 가중치 갱신 횟수는 다르다.
- 구조·학습률·초기화·배치 크기·은닉 뉴런 수가 성능과 속도에 영향을 준다.
- **MNIST**: 0~9 손글씨, 28×28 흑백 영상, 학습 60,000개·테스트 10,000개. MLP 입력 784, 단일 정답 분류 출력 10. 픽셀을 255로 나눠 정규화할 수 있다.

> 주의: 검증셋 분할 방식과 모델 구조에 따라 성능은 달라진다. 강의 예제의 정확도를 모든 MLP의 고정 성능으로 외우지 않는다.

## CNN과 학습 성능 개선

**CNN은 국소 연결과 가중치 공유로 영상·격자 데이터의 특징을 추출한다.**

| 요소 | 역할 |
|---|---|
| 합성곱 | 필터를 이동하며 특징맵 생성, 필터 가중치를 학습 |
| 패딩 | 경계에 값을 추가해 공간 크기·가장자리 정보 조절 |
| 스트라이드 | 필터의 이동 간격 |
| 풀링 | 각 영역을 최댓값·평균 등으로 요약, 공간 크기 감소 |

- 일반적인 공간 풀링은 **채널 수 유지**, **학습하는 가중치 없음**. 창 크기·스트라이드는 설정하는 하이퍼파라미터다.
- 합성곱 출력 크기(한 축, dilation=1): `floor((N+2P−F)/S)+1`. N 입력 크기, P 패딩, F 필터, S 스트라이드.
- **느린 학습**: 활성화·초기화 개선, 모멘텀, RMSProp·Adam 등 적응적 학습률, 배치 정규화.
- **과적합**: 조기 종료, 정규항, 드롭아웃, 데이터 증대.
- SGD의 확률적 변화나 시뮬레이티드 어닐링은 좋지 않은 국소해에서 벗어나는 데 도움을 줄 수 있지만 전역 최적을 보장하지 않는다.

> 주의: 풀링에 학습 파라미터가 없다는 말은 설정할 값도 없다는 뜻이 아니다. 합성곱 출력 채널 수는 필터 수와 연결된다.

## RNN·LSTM·GRU

**순차 데이터는 순서·가변 길이·문맥이 중요하다.** RNN은 이전 은닉 상태와 현재 입력으로 현재 상태를 계산하며 시간축에서 가중치를 공유한다.

- 입력/출력 형태: 1:m(영상설명 등), m:1(문장 분류 등), m:n(번역 등).
- 다층 RNN은 층을 쌓고, 양방향 RNN은 앞·뒤 문맥을 함께 이용한다.
- **BPTT**: 시간축으로 펼친 계산 그래프에 역전파를 적용한다.
- 긴 시간축에서 기울기가 반복 곱해져 **소멸·폭발**할 수 있다. 먼 과거 정보를 활용하기 어려운 것이 **장기 의존성 문제**다.

| 모델 | 기억 구조·게이트 |
|---|---|
| 기본 RNN | 은닉 상태, 장기 의존성에 취약 |
| LSTM | 셀 상태, **망각·입력·출력** 3게이트 |
| GRU | 단순화된 구조, **리셋·갱신** 2게이트 |

- 망각: 이전 기억 유지량 / 입력: 새 기억 반영량 / 출력: 외부로 전달할 정보.
- GRU 리셋: 과거 정보의 사용 정도 / 갱신: 과거 상태와 새 상태를 섞는 정도.
- LSTM·GRU는 장기 의존성·기울기 소멸을 완화한다. 기울기 폭발에는 클리핑도 사용한다.

> 주의: “LSTM 3개, GRU 2개”는 게이트 개수다. 모든 문제에서 특정 모델이 반드시 더 우수한 것은 아니다.

## 영상 인식·검출·생성

| 모델·계열 | 시험 구분점 |
|---|---|
| AlexNet | 2012 ILSVRC, 5개 합성곱층 + 3개 완전연결층 |
| VGG | 11·13·16·19층 변형, 작은 필터를 깊게 쌓음 |
| GoogLeNet | Inception 모듈, 원문 예시 22층 |
| ResNet | Residual 모듈·skip connection, 152층은 한 변형 |
| R-CNN / Faster R-CNN | 영역 기반 객체검출, Faster R-CNN은 영역 제안망 활용 |
| YOLO | 한 번의 네트워크 흐름으로 위치·클래스 예측, 실시간 검출 |
| Show and Tell | 영상 특징 + LSTM으로 영상설명 |
| Show, Attend and Tell | 영상설명에 Attention 추가 |

- **객체인식**: 무엇인가 / **검출**: 무엇이 어디 있는가 / **분할**: 픽셀별 영역은 무엇인가.
- **오토인코더**: Encoder → 잠재 표현 z → Decoder, 입력을 복원하도록 학습해 유용한 표현을 얻는다.
- **U-Net**: 인코더·디코더와 skip connection을 갖는 U자 구조, 의료영상 분할에 사용.
- **GAN**: 생성기 G는 진짜 같은 데이터를 생성, 판별기 D는 진짜/가짜를 구분하도록 경쟁적으로 학습.

> 주의: Inception은 GoogLeNet, Residual은 ResNet. U-Net은 분할 모델이다. GAN의 두 모델은 같은 목적함수를 같은 방향으로 최소화하는 관계가 아니다.

## 자연어처리와 Transformer

| 단계·표현 | 핵심 |
|---|---|
| 토큰화 / 정제 / 정규화 | 기본 단위로 나누기 / 노이즈 제거 / 표현 통일 |
| One-hot | 고차원 희소 벡터, 의미 유사성을 직접 표현하지 못함 |
| BoW / DTM | 단어 빈도 / 문서×단어 빈도 행렬, 어순 무시 |
| TF-IDF | 문서 내 빈도와 전체 문서에서의 희소성을 함께 반영 |
| Word Embedding | 의미를 반영하는 저차원 밀집 실수 벡터 |
| Word2Vec CBOW | 주변 단어 → 중심 단어 |
| Word2Vec Skip-gram | 중심 단어 → 주변 단어 |

- DF는 해당 단어가 등장한 **문서 수**. TF-IDF의 IDF는 보통 DF가 클수록 작아진다.
- 언어 모델은 단어·토큰 시퀀스의 확률을 모델링한다.
- **Seq2Seq**: Encoder → Decoder. 기본 고정 길이 문맥 벡터는 긴 입력의 정보 병목이 될 수 있다.
- **Attention**: 현재 출력에 필요한 입력 위치의 정보를 가중 결합한다.
- **Transformer**: 순환 구조 대신 Attention을 중심으로 구성하고 위치 정보를 함께 제공한다.
- **BERT**: Transformer Encoder 기반 사전학습. 원문 기준 입력 표현은 **Token + Segment + Position**.
- LLM 흐름: 대규모 사전학습 → 목적에 맞는 미세조정 → 추론·평가. **Few-shot CoT**는 풀이 예시 제공, **Zero-shot CoT**는 예시 없이 단계적 추론 지시.

> 주의: CBOW와 Skip-gram의 방향을 거꾸로 외우지 말 것. Attention은 모든 정보를 하나의 고정 벡터로만 압축하는 방식과 구분한다.

## 강화학습과 DQN

**에이전트가 환경과 상호작용하며 기대 누적 보상을 높이는 정책을 학습한다.**

- **MDP 5요소**: 상태 S, 행동 A, 상태전이확률 P, 보상 R, 할인율 γ.
- **마르코프 성질**: 현재 상태와 행동이 주어지면 다음 상태·보상의 분포가 과거 이력에 추가로 의존하지 않는다.
- 정책 π는 행동 선택 규칙. 수익은 `Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …`.
- **V(s)**: 상태 s에서 시작해 정책을 따를 때의 기대 수익. **Q(s,a)**: s에서 a를 한 뒤 정책을 따를 때의 기대 수익.
- **Q-학습**: `Q(s,a) ← Q(s,a) + α[r + γ max Q(s′,a′) − Q(s,a)]`. 종료 상태에서는 다음 상태의 미래 수익 항을 0으로 둔다.

| 구분 | 핵심 |
|---|---|
| 탐험(Exploration) | 새로운 행동으로 정보 수집 |
| 활용(Exploitation) | 현재 Q값 기준 좋은 행동 선택, 원문의 “탐사” |
| ε-greedy | 확률 ε로 탐험, 나머지는 현재 최선 선택 |
| Q-테이블 | 상태·행동별 값 저장, 큰 상태 공간에 비효율적 |
| Q-신경망 | 상태를 입력받아 행동별 Q값을 근사 |
| DQN | 심층 신경망으로 Q 근사, 영상 입력에는 CNN 활용 가능 |

- **DQN 안정화**: 경험 재현으로 과거 전이를 섞어 학습, 목표망으로 학습 목표의 급변 완화.
- 결정론적 환경은 주어진 상태·행동에서 결과가 정해지고, 확률적 환경은 결과가 확률적으로 달라질 수 있다.

> 주의: 마르코프 성질이 행동을 항상 결정론적으로 고른다는 뜻은 아니다. DQN의 CNN 층수는 고정된 정의가 아니라 구현·강의 예제에 따라 달라진다.
